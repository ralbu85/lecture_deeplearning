객체탐지

학습 목표
  • 분류와 객체탐지의 출력이 어떻게 다른지 설명한다
  • 바운딩 박스를 (x, y, w, h)로 읽고 쓴다
  • 두 박스의 IoU를 직접 계산한다
  • NMS 절차를 따라 겹친 박스를 정리한다
  • IoU로 예측이 맞았는지 판정한다

8장까지 다룬 CNN은 사진 한 장을 받아 그것이 무엇인지를 클래스 하나로 답했다. 그런데 자율주행 자동차의 카메라라면 앞에 자동차가 있다는 것만으로는 부족하고, 그 자동차가 어디에 있는지, 사람은 몇 명이나 있는지까지 알아야 한다. 이렇게 사진 속 물체의 종류와 위치를 함께 찾는 일을 객체탐지라고 한다. 객체탐지는 컴퓨터 비전에서 가장 널리 쓰이는 응용 가운데 하나다.

분류에서 탐지로

같은 사진을 두 모델에 넣어 보자. 분류 모델은 “자동차”라고 답하고 끝난다. 탐지 모델은 자동차가 있는 자리에 박스를 그리고 “자동차”라고 적는다. 사진에 사람도 있으니 사람에게도 박스를 그린다.

객체탐지 (Object Detection)

이미지 안의 물체마다 위치(바운딩 박스)와 종류(클래스)를 함께 찾는 작업.

탐지의 출력: 분류와 회귀

탐지 모델이 물체 하나에 대해 내는 답을 나눠 보면 이미 배운 두 가지로 이루어져 있다. 물체가 무엇인지는 클래스를 고르는 분류이고, 물체가 어디에 있는지는 박스의 위치를 숫자로 맞히는 회귀다.

바운딩 박스

바운딩 박스 (Bounding Box)

물체를 둘러싸는 직사각형. 왼쪽 위 모서리의 좌표 \((x, y)\)와 너비 \(w\), 높이 \(h\), 숫자 네 개로 나타낸다.

이미지의 좌표는 왼쪽 위가 \((0, 0)\)이고, \(x\)는 오른쪽으로, \(y\)는 아래로 갈수록 커진다. 그래서 박스의 오른쪽 아래 모서리는 \((x + w,\ y + h)\)다. 모델은 이 숫자 네 개를 맞혀야 하므로, 박스를 찾는 일은 1장에서 본 회귀와 같다.

출력 하나에 들어 있는 것

모델은 박스마다 클래스 확률과 박스 좌표, 그리고 신뢰도를 함께 낸다. 클래스 확률은 3장의 Softmax로 구한 분류의 출력이고, 박스 좌표는 회귀의 출력이다.

신뢰도 (Confidence)

예측한 박스 안에 물체가 있을 확률.

신뢰도가 왜 필요한지는 출력의 개수를 생각해 보면 알 수 있다.

출력의 개수가 정해져 있지 않다

분류 모델은 사진이 무엇이든 클래스 확률을 정해진 개수만큼 냈다. 탐지는 다르다. 물체가 하나면 답도 하나, 셋이면 셋이어야 하고, 물체가 없으면 답도 없어야 한다.

그래서 탐지 모델은 물체가 있을 만한 자리마다 후보 박스를 넉넉히 내놓고, 후보마다 신뢰도를 붙인다. 신뢰도가 낮은 후보를 버리면 물체가 있는 자리의 박스만 남는다.

그런데 오른쪽 그림을 보면 한 물체에 박스가 아직 여러 개 남아 있다. 이 문제는 뒤에서 NMS로 정리한다.

정답 만들기: 레이블링

모델을 학습시키려면 출력과 같은 모양의 정답이 있어야 한다. 분류에서는 사진마다 클래스 하나를 적으면 됐지만, 탐지에서는 사람이 사진 위에 물체마다 박스를 그리고 클래스를 붙여야 한다. 이렇게 만든 정답을 레이블이라고 한다.

레이블은 물체마다 (클래스, \(x\), \(y\), \(w\), \(h\)) 한 줄이다. 사진 한 장에 물체가 셋이면 세 줄이 된다.

박스가 얼마나 맞았나: IoU

레이블이 있으면 예측 박스와 정답 박스를 비교할 수 있다. 가장 먼저 떠오르는 방법은 좌표의 차이를 재는 것이지만, 같은 차이라도 물체의 크기에 따라 의미가 달라진다.

버스와 사람 모두 예측 박스가 정답보다 10픽셀 오른쪽으로 밀려 있다. 버스에서는 박스가 거의 그대로 겹치지만, 작은 사람에서는 절반이 빗나갔다. 그래서 박스가 얼마나 맞았는지는 좌표의 차이가 아니라 두 박스가 겹친 비율로 잰다.

IoU (Intersection over Union)

두 박스가 겹친 넓이(교집합)를 둘 중 하나라도 덮은 넓이(합집합)로 나눈 값.

\[\text{IoU} = \frac{A \cap B}{A \cup B} = \frac{A \cap B}{A + B - A \cap B}\]

두 박스가 완전히 일치하면 1, 전혀 겹치지 않으면 0이다.

합집합을 구할 때 겹친 부분을 한 번 빼는 것은, 두 박스의 넓이를 더하면 겹친 부분이 두 번 들어가기 때문이다.

칸을 세어 계산하기

모눈 위에 정답 박스 \((x=2,\ y=1,\ w=4,\ h=3)\)와 예측 박스 \((x=4,\ y=2,\ w=4,\ h=3)\)를 그리고 칸을 세어 보자.

두 박스는 각각 12칸이고 4칸이 겹친다. 합집합은 \(12 + 12 - 4 = 20\)칸이므로 IoU는 \(4 / 20 = 0.20\)이다.

좌표로 계산하기

실제로는 모눈이 없으니 좌표로 계산한다. 교집합도 직사각형이므로 모서리만 구하면 된다. 교집합이 시작하는 곳은 두 박스의 시작점 가운데 큰 값이고, 끝나는 곳은 두 박스의 끝점 가운데 작은 값이다.

단계 계산 결과
1. 박스를 모서리로 정답: \(x\) 2~6, \(y\) 1~4 / 예측: \(x\) 4~8, \(y\) 2~5
2. 교집합의 \(x\) 범위 max(2, 4) ~ min(6, 8) 4~6, 너비 2
3. 교집합의 \(y\) 범위 max(1, 2) ~ min(4, 5) 2~4, 높이 2
4. 교집합 넓이 2 × 2 4
5. 합집합 넓이 12 + 12 − 4 20
6. IoU 4 ÷ 20 0.20

두 박스가 떨어져 있으면 2단계나 3단계에서 끝나는 곳이 시작하는 곳보다 앞에 온다. 이때는 교집합의 너비나 높이를 0으로 보고, IoU도 0이 된다.

박스를 움직여 보기

예측 박스를 움직이거나 크기를 바꿔 IoU가 어떻게 변하는지 보자. 정답 박스는 위와 같다.

viewof px = Inputs.range([0, 6], {step: 1, value: 4, label: "예측 박스 x"})
viewof py = Inputs.range([0, 4], {step: 1, value: 2, label: "예측 박스 y"})
viewof pw = Inputs.range([1, 4], {step: 1, value: 4, label: "예측 박스 w"})
viewof ph = Inputs.range([1, 3], {step: 1, value: 3, label: "예측 박스 h"})
{
  const A = {x: 2, y: 1, w: 4, h: 3}, B = {x: px, y: py, w: pw, h: ph};
  const ix = Math.max(0, Math.min(A.x + A.w, B.x + B.w) - Math.max(A.x, B.x));
  const iy = Math.max(0, Math.min(A.y + A.h, B.y + B.h) - Math.max(A.y, B.y));
  const inter = ix * iy, uni = A.w * A.h + B.w * B.h - inter, v = inter / uni;
  const cs = 34, gx = 20, gy = 16, W = 680, H = 270;
  const svg = d3.create("svg").attr("viewBox", `0 0 ${W} ${H}`).attr("width", "100%").style("max-width", `${W}px`).style("font-family", "Pretendard, sans-serif");
  for (let i = 0; i <= 10; i++) svg.append("line").attr("x1", gx + i * cs).attr("y1", gy).attr("x2", gx + i * cs).attr("y2", gy + 7 * cs).attr("stroke", "#E0E0E0");
  for (let j = 0; j <= 7; j++) svg.append("line").attr("x1", gx).attr("y1", gy + j * cs).attr("x2", gx + 10 * cs).attr("y2", gy + j * cs).attr("stroke", "#E0E0E0");
  const rect = (r, fill, op, stroke, dash) => svg.append("rect").attr("x", gx + r.x * cs).attr("y", gy + r.y * cs).attr("width", r.w * cs).attr("height", r.h * cs)
    .attr("fill", fill).attr("fill-opacity", op).attr("stroke", stroke).attr("stroke-width", stroke === "none" ? 0 : 2.2).attr("stroke-dasharray", dash ? "6,4" : null);
  rect(A, "#2E7D32", 0.18, "#2E7D32", false);
  rect(B, "#1565C0", 0.18, "#1565C0", true);
  if (inter > 0) rect({x: Math.max(A.x, B.x), y: Math.max(A.y, B.y), w: ix, h: iy}, "#6A1B9A", 0.45, "none", false);
  const tx = gx + 10 * cs + 30;
  const t = (y, s, c, size = 14) => svg.append("text").attr("x", tx).attr("y", y).attr("font-size", size).attr("font-weight", 700).attr("fill", c).text(s);
  t(40, `정답 박스: ${A.w * A.h}칸`, "#2E7D32");
  t(68, `예측 박스: ${B.w * B.h}칸`, "#1565C0");
  t(96, `겹친 부분: ${inter}칸`, "#6A1B9A");
  t(134, `합집합: ${A.w * A.h} + ${B.w * B.h} - ${inter} = ${uni}칸`, "#222");
  t(172, `IoU = ${inter} / ${uni} = ${v.toFixed(2)}`, "#222", 17);
  t(206, v >= 0.5 ? "0.5 이상: 맞은 박스로 본다" : "0.5 미만: 빗나간 박스로 본다", v >= 0.5 ? "#2E7D32" : "#C62828");
  return svg.node();
}

연습

정답 박스 \((x=1,\ y=1,\ w=4,\ h=4)\)와 예측 박스 \((x=3,\ y=3,\ w=4,\ h=4)\)의 IoU를 구하라.

✍️ 직접 해보기 — 풀이

정답은 \(x\) 1~5, \(y\) 1~5이고 예측은 \(x\) 3~7, \(y\) 3~7이다. 교집합은 \(x\) max(1, 3) ~ min(5, 7) = 3~5, \(y\)도 3~5이므로 넓이 \(2 \times 2 = 4\)다. 합집합은 \(16 + 16 - 4 = 28\)이고 IoU는 \(4 / 28 = \mathbf{0.14}\)다.

학습: 클래스 손실과 박스 손실

학습의 원리는 3장과 같다. 출력과 레이블의 차이를 손실로 계산하고, 경사하강법으로 손실이 줄어드는 방향으로 가중치를 고친다. 다른 점은 출력이 클래스와 박스 두 부분이라 손실도 두 부분이라는 것이다.

클래스는 분류이므로 교차 엔트로피로 비교한다. 정답 클래스인 자동차의 확률이 0.92라면 손실은 \(-\ln 0.92 = 0.08\)이다. 박스는 IoU로 비교한다. IoU는 1에 가까울수록 좋으므로 \(1 - \text{IoU}\)를 손실로 쓰면, IoU가 0.75일 때 박스 손실은 0.25다. 둘을 더한 0.33이 이 물체의 손실이 되고, 학습은 이 값을 줄여 나간다.

출력 정리: NMS

학습이 끝난 모델에 사진을 넣으면, 앞에서 본 것처럼 신뢰도로 걸러도 한 물체에 박스가 여러 개 남는다. 같은 물체를 가리키는 박스는 하나만 남겨야 하는데, 두 박스가 같은 물체를 가리키는지는 IoU로 판단한다. 많이 겹치면 같은 물체를 본 것이다.

NMS (Non-Maximum Suppression, 비최대 억제)

겹치는 예측 박스 가운데 신뢰도가 가장 높은 것만 남기고 나머지를 지우는 절차.

  1. 남은 박스 가운데 신뢰도가 가장 높은 박스를 채택한다
  2. 채택한 박스와 IoU가 0.5 이상인 박스를 모두 지운다
  3. 남은 박스가 없을 때까지 1~2를 반복한다

후보 박스 다섯 개로 따라가 보자. 신뢰도가 높은 순서는 B1(0.95), B4(0.90), B2(0.80), B5(0.70), B3(0.60)이다.

단계 채택하는 박스 채택한 박스와의 IoU 지우는 박스
1 B1 (0.95) B2 0.72, B3 0.64, B4 0.00, B5 0.00 B2, B3
2 B4 (0.90) B5 0.56 B5
결과 B1, B4

자동차에는 B1, 사람에는 B4가 하나씩 남았다. B1과 B4는 IoU가 0이라 서로 다른 물체로 보고 둘 다 남긴다.

맞았는지 판정

남은 박스가 맞았는지를 정할 때도 IoU를 쓴다. 예측 박스와 정답 박스의 IoU가 0.5 이상이고 클래스도 같을 때 맞은 것으로 본다.

예측 정답 IoU 판정
자동차 자동차 0.73 맞음
사람 사람 0.12 틀림
자동차 사람 0.79 틀림

두 번째 예측은 클래스는 맞았지만 박스가 정답과 거의 겹치지 않아 틀린 것으로 본다. 세 번째 예측은 박스는 거의 맞았지만 사람을 자동차로 잘못 보았으므로 역시 틀렸다.

탐지 모델도 전이 학습으로

탐지 모델을 처음부터 학습시키려면 박스 레이블이 달린 사진이 아주 많이 필요하다. 그래서 8장의 분류 모델처럼 대량의 데이터로 사전 학습한 탐지 모델을 가져와 쓴다. COCO는 사진 약 12만 장에 80개 클래스의 박스를 그려 둔 데이터셋인데, 여기서 학습한 탐지 모델이 공개되어 있다. 내 사진 수백 장에 박스를 그려 이 모델을 미세 조정하면, 내가 원하는 물체를 찾는 탐지 모델을 만들 수 있다.
