객체탐지는 이미지 안에 있는 물체의 종류와 위치를 함께 찾는 컴퓨터 비전 분야이다.

객체탐지 (Object Detection)

이미지 안의 물체마다 위치(바운딩 박스)와 종류(클래스)를 함께 찾는 작업.

탐지 모델은 8장까지 다룬 분류 모델과 출력의 형태가 다르다. 같은 이미지에 대해 분류 모델은 “자동차”라는 클래스 하나를 출력하므로, 이미지에 무엇이 있는지는 알 수 있지만 그 물체가 어디에 몇 개 있는지는 알 수 없다. 반면 탐지 모델은 자동차와 사람 각각의 위치에 박스를 그리고 그 박스마다 클래스를 붙여 출력한다.

객체탐지는 자율주행, 제조, 의료, 보안 등 다양한 산업 현장에서 활용되며 오늘날 각광받는 분야이다. 실제 현장에서는 물체가 무엇인지뿐 아니라 어디에 몇 개 있는지까지 알아야 판단을 내릴 수 있는 경우가 많다. 다음 표는 객체탐지가 활발하게 적용되는 분야이다. 아래의 표와 같이 이미지의 분류와 함께 위치를 특정할 수 있음으로써 정지, 공정 점검, 경보와 같은 구체적인 조치를 결정할 수 있다.

탐지 모델의 출력: 분류와 회귀

객체탐지 모델을 이해하려면 모델이 무엇을 출력하는지, 그 출력을 정답과 어떻게 비교하여 학습시키는지, 학습된 모델의 출력을 어떻게 정리하고 평가하는지를 알아야 한다. 이 장에서는 이 순서에 따라 탐지 모델의 출력, IoU, 레이블링과 레이블 할당, 손실, NMS, 정답 판정을 차례로 다루고, 마지막으로 탐지 모델의 전이 학습과 대표적인 객체탐지 모델을 다룬다.

탐지 모델의 출력은 분류와 회귀의 두 부분으로 이루어진다. 물체의 종류를 찾는 것은 정해진 클래스 중 하나를 고르는 분류이고, 물체의 위치를 찾는 것은 박스의 좌표를 숫자로 예측하는 회귀이다.

바운딩 박스

탐지 모델이 물체의 위치를 출력하려면 위치를 숫자로 나타내는 방법이 필요하다. 물체의 모양은 제각각이므로 윤곽선을 그대로 따라 그리면 물체마다 필요한 숫자의 개수가 달라진다. 반면 물체를 둘러싸는 직사각형으로 나타내면 어떤 물체든 위치를 숫자 네 개로 똑같이 표현할 수 있으므로, 모델이 정해진 형태의 숫자를 출력할 수 있다. 이 직사각형을 바운딩 박스라고 한다.

바운딩 박스 (Bounding Box)

물체를 둘러싸는 직사각형. 왼쪽 위 모서리의 좌표 \((x, y)\)와 너비 \(w\), 높이 \(h\), 숫자 네 개로 나타낸다.

이미지의 좌표는 왼쪽 위를 \((0, 0)\)으로 하며, \(x\)는 오른쪽으로, \(y\)는 아래로 갈수록 커진다. 따라서 박스의 오른쪽 아래 모서리는 \((x + w,\ y + h)\)이다. 바운딩 박스를 찾는 것은 이 네 개의 숫자를 예측하는 것이므로 1장에서 본 회귀에 해당한다.

클래스 확률, 박스 좌표, 신뢰도

물체의 위치를 바운딩 박스로 특정했다면, 그다음은 바운딩 박스 내에 있는 이미지가 무엇인지 분류하는 과정이 필요하다. 이를 위해 탐지 모델은 박스마다 3장의 Softmax로 구한 클래스 확률을 출력한다. 또한 객체탐지 모델은 바운딩 박스마다 신뢰도라는 별도의 지표를 출력하는데, 이는 박스 안에 물체가 실제로 있을 확률을 뜻하는 것으로 물체의 종류를 나타내는 클래스 확률과는 별도의 값이다.

신뢰도 (Confidence)

예측한 박스 안에 물체가 있을 확률.

출력 개수와 후보 박스

분류 모델은 어떤 이미지가 들어와도 정해진 개수의 클래스 확률을 출력하지만, 탐지 모델은 이미지 안에 있는 물체의 수만큼 박스를 출력해야 하므로 아래 그림과 같이 이미지마다 출력의 개수가 달라진다. 그런데 뉴럴 네트워크는 출력층의 노드 수가 모델의 구조로 정해져 있으므로, 이미지마다 개수가 달라지는 박스를 그대로 출력할 수 없다.

이를 해결하기 위해 탐지 모델은 많은 수의 바운딩 박스를 출력하도록 뉴럴 네트워크를 미리 구성해 두고, 이미지에 물체가 몇 개 있든 항상 그 수만큼 박스를 만든다. 이렇게 만든 박스를 후보 박스라고 한다. 그리고 앞에서 정의한 신뢰도를 이용하여 신뢰도가 높은 후보 박스만 남기고 나머지는 제거한다. 예를 들어 아래 그림에서는 후보 박스 8개 중 신뢰도가 0.5 이상인 5개만 남는다.

하지만 위 그림의 오른쪽과 같이 신뢰도로 거른 뒤에도 한 물체에 여러 개의 박스가 남을 수 있다.

IoU (Intersection over Union)

IoU는 두 박스가 얼마나 일치하는지를 나타내는 값으로, 예측 박스가 정답 박스와 얼마나 맞는지를 잴 때 사용한다. 박스의 일치 정도를 좌표의 차이로 잴 수도 있지만, 같은 좌표 차이라도 물체의 크기에 따라 의미가 달라진다. 예를 들어 다음 그림에서 버스와 사람의 예측 박스는 모두 정답보다 10픽셀 오른쪽으로 밀려 있다.

큰 버스에서는 두 박스가 거의 그대로 겹치지만, 작은 사람에서는 박스의 절반이 빗나간다. 따라서 박스의 일치 정도는 좌표의 차이가 아니라 두 박스가 겹친 비율로 측정한다.

IoU (Intersection over Union)

두 박스가 겹친 넓이(교집합)를 둘 중 하나라도 덮은 넓이(합집합)로 나눈 값.

\[\text{IoU} = \frac{A \cap B}{A \cup B} = \frac{A \cap B}{A + B - A \cap B}\]

두 박스가 완전히 일치하면 1, 전혀 겹치지 않으면 0이다.

두 박스의 넓이를 더하면 겹친 부분이 두 번 더해지므로, 합집합의 넓이는 두 박스의 넓이의 합에서 교집합을 한 번 뺀 값이다.

칸을 세어 계산하기

예를 들어 정답 박스 \((x=2,\ y=1,\ w=4,\ h=3)\)와 예측 박스 \((x=4,\ y=2,\ w=4,\ h=3)\)를 모눈 위에 그리면 다음과 같다.

두 박스의 넓이는 각각 12칸이고, 겹친 부분은 4칸이다. 따라서 합집합은 \(12 + 12 - 4 = 20\)칸이고, IoU는 \(4 / 20 = 0.20\)이다.

좌표로 계산하기

실제 이미지에서는 칸을 셀 수 없으므로 박스의 좌표로 IoU를 계산한다. 교집합도 직사각형이므로 교집합의 모서리 좌표를 구하면 넓이를 계산할 수 있다. 교집합의 시작점은 두 박스의 시작점 중 큰 값이고, 끝점은 두 박스의 끝점 중 작은 값이다. 위의 예시를 좌표로 계산하면 다음과 같다.

단계 계산 결과
1. 박스를 모서리로 정답: \(x\) 2~6, \(y\) 1~4 / 예측: \(x\) 4~8, \(y\) 2~5
2. 교집합의 \(x\) 범위 max(2, 4) ~ min(6, 8) 4~6, 너비 2
3. 교집합의 \(y\) 범위 max(1, 2) ~ min(4, 5) 2~4, 높이 2
4. 교집합 넓이 2 × 2 4
5. 합집합 넓이 12 + 12 − 4 20
6. IoU 4 ÷ 20 0.20

두 박스가 떨어져 있으면 교집합의 끝점이 시작점보다 작아지는데, 이때는 교집합의 너비나 높이를 0으로 두므로 IoU도 0이 된다.

예측 박스에 따른 IoU의 변화

다음은 정답 박스를 위의 예시와 같이 두고, 예측 박스의 위치와 크기에 따라 IoU가 어떻게 달라지는지 나타낸 것이다.

viewof px = Inputs.range([0, 6], {step: 1, value: 4, label: "예측 박스 x"})
viewof py = Inputs.range([0, 4], {step: 1, value: 2, label: "예측 박스 y"})
viewof pw = Inputs.range([1, 4], {step: 1, value: 4, label: "예측 박스 w"})
viewof ph = Inputs.range([1, 3], {step: 1, value: 3, label: "예측 박스 h"})
{
  const A = {x: 2, y: 1, w: 4, h: 3}, B = {x: px, y: py, w: pw, h: ph};
  const ix = Math.max(0, Math.min(A.x + A.w, B.x + B.w) - Math.max(A.x, B.x));
  const iy = Math.max(0, Math.min(A.y + A.h, B.y + B.h) - Math.max(A.y, B.y));
  const inter = ix * iy, uni = A.w * A.h + B.w * B.h - inter, v = inter / uni;
  const cs = 34, gx = 20, gy = 16, W = 680, H = 270;
  const svg = d3.create("svg").attr("viewBox", `0 0 ${W} ${H}`).attr("width", "100%").style("max-width", `${W}px`).style("font-family", "Pretendard, sans-serif");
  for (let i = 0; i <= 10; i++) svg.append("line").attr("x1", gx + i * cs).attr("y1", gy).attr("x2", gx + i * cs).attr("y2", gy + 7 * cs).attr("stroke", "#E0E0E0");
  for (let j = 0; j <= 7; j++) svg.append("line").attr("x1", gx).attr("y1", gy + j * cs).attr("x2", gx + 10 * cs).attr("y2", gy + j * cs).attr("stroke", "#E0E0E0");
  const rect = (r, fill, op, stroke, dash) => svg.append("rect").attr("x", gx + r.x * cs).attr("y", gy + r.y * cs).attr("width", r.w * cs).attr("height", r.h * cs)
    .attr("fill", fill).attr("fill-opacity", op).attr("stroke", stroke).attr("stroke-width", stroke === "none" ? 0 : 2.2).attr("stroke-dasharray", dash ? "6,4" : null);
  rect(A, "#2E7D32", 0.18, "#2E7D32", false);
  rect(B, "#1565C0", 0.18, "#1565C0", true);
  if (inter > 0) rect({x: Math.max(A.x, B.x), y: Math.max(A.y, B.y), w: ix, h: iy}, "#6A1B9A", 0.45, "none", false);
  const tx = gx + 10 * cs + 30;
  const t = (y, s, c, size = 14) => svg.append("text").attr("x", tx).attr("y", y).attr("font-size", size).attr("font-weight", 700).attr("fill", c).text(s);
  t(40, `정답 박스: ${A.w * A.h}칸`, "#2E7D32");
  t(68, `예측 박스: ${B.w * B.h}칸`, "#1565C0");
  t(96, `겹친 부분: ${inter}칸`, "#6A1B9A");
  t(134, `합집합: ${A.w * A.h} + ${B.w * B.h} - ${inter} = ${uni}칸`, "#222");
  t(172, `IoU = ${inter} / ${uni} = ${v.toFixed(2)}`, "#222", 17);
  t(206, v >= 0.5 ? "0.5 이상: 맞은 박스로 본다" : "0.5 미만: 빗나간 박스로 본다", v >= 0.5 ? "#2E7D32" : "#C62828");
  return svg.node();
}

연습

정답 박스 \((x=1,\ y=1,\ w=4,\ h=4)\)와 예측 박스 \((x=3,\ y=3,\ w=4,\ h=4)\)의 IoU를 구하라.

✍️ 직접 해보기 — 풀이

정답은 \(x\) 1~5, \(y\) 1~5이고 예측은 \(x\) 3~7, \(y\) 3~7이다. 교집합은 \(x\) max(1, 3) ~ min(5, 7) = 3~5, \(y\)도 3~5이므로 넓이 \(2 \times 2 = 4\)다. 합집합은 \(16 + 16 - 4 = 28\)이고 IoU는 \(4 / 28 = \mathbf{0.14}\)다.

레이블링과 레이블 할당

탐지 모델을 학습시키려면 모델의 출력과 같은 형태의 정답이 필요하다. 분류에서는 이미지마다 클래스 하나를 정답으로 적으면 되지만, 탐지에서는 사람이 이미지 위에 물체마다 박스를 그리고 클래스를 붙여야 한다. 이렇게 만든 정답을 레이블이라고 하고, 레이블을 만드는 작업을 레이블링이라고 한다.

레이블은 물체 하나마다 (클래스, \(x\), \(y\), \(w\), \(h\))의 한 줄로 기록되므로, 이미지 한 장에 물체가 세 개 있으면 레이블도 세 줄이 된다.

레이블 할당

탐지 모델은 이미지마다 항상 같은 수의 후보 박스를 출력하지만, 레이블에는 이미지 안에 있는 물체의 수만큼만 박스가 있다. 손실을 계산하려면 후보 박스마다 비교할 정답이 있어야 하므로, 각 후보 박스가 어떤 레이블 박스를 맡을지를 정해야 한다. 이를 레이블 할당이라고 한다.

레이블 할당 (Label Assignment)

후보 박스마다 IoU를 이용하여 비교할 레이블 박스를 정하는 것. IoU가 기준값(예: 0.5) 이상인 레이블 박스가 있으면 그 물체를 맡고, 없으면 배경으로 본다.

여기서 배경은 이미지에서 찾으려는 클래스의 물체가 없는 영역을 뜻한다. 자동차와 사람을 찾는 모델이라면 하늘, 도로 바닥, 건물 벽이 모두 배경이다. 예를 들어 레이블에 자동차 박스 하나가 있고 모델이 후보 박스 다섯 개를 출력했다면, 각 후보 박스의 레이블 할당 결과는 다음과 같다.

후보 박스 레이블 박스와의 IoU 할당 결과 학습하는 내용
C1 0.82 자동차 신뢰도 1, 클래스와 박스를 레이블에 맞춤
C2 0.61 자동차 신뢰도 1, 클래스와 박스를 레이블에 맞춤
C3 0.20 배경 신뢰도 0
C4 0.00 배경 신뢰도 0
C5 0.00 배경 신뢰도 0

자동차를 맡은 후보 박스는 신뢰도가 1에 가까워지도록 학습하고, 클래스와 박스도 레이블에 가까워지도록 학습한다. 반면 배경으로 할당된 후보 박스는 맞힐 물체가 없으므로 신뢰도가 0에 가까워지도록만 학습한다. 레이블 박스가 여러 개라면 후보 박스마다 모든 레이블 박스와 IoU를 구하여 가장 많이 겹치는 레이블 박스를 할당한다. 따라서 레이블은 물체의 수만큼만 있으면 되고, 모든 후보 박스의 정답은 레이블 할당을 통해 만들어진다.

탐지 모델의 손실: 클래스 손실과 박스 손실

레이블 할당으로 후보 박스마다 정답이 정해졌다면, 그다음은 모델의 출력이 정답과 얼마나 다른지를 계산해야 한다. 이 차이를 하나의 숫자로 나타낸 것이 손실이며, 탐지 모델도 3장에서 본 것처럼 경사하강법으로 이 손실을 줄이는 방향으로 학습한다. 탐지 모델의 출력은 아래 그림처럼 클래스와 박스의 두 부분으로 이루어지므로, 손실도 클래스 손실과 박스 손실의 합으로 계산한다. 클래스 손실은 분류 모델의 손실과 같은 개념으로, 교차 엔트로피로 계산한다. 반면 박스 손실은 탐지에서 새로 등장하는 개념으로, 예측 박스가 정답 박스와 얼마나 어긋나는지를 나타내는 값이다.

박스 손실 (Box Loss)

예측 박스가 정답 박스와 어긋난 정도를 나타내는 손실. 이 장에서는 IoU를 이용하여 다음과 같이 계산한다.

\[\text{박스 손실} = 1 - \text{IoU}\]

IoU는 두 박스가 완전히 일치하면 1, 전혀 겹치지 않으면 0이므로, 박스 손실은 예측 박스가 정답 박스와 정확히 일치할 때 0이 되고 어긋날수록 커져 최대 1이 된다. 따라서 박스 손실을 줄이도록 학습하면 예측 박스가 정답 박스에 점점 가까워진다.

NMS (Non-Maximum Suppression)

학습이 끝난 탐지 모델에 이미지를 넣으면, 앞의 “출력 개수와 후보 박스”에서 본 것처럼 신뢰도가 낮은 후보 박스를 제거하더라도 한 물체에 여러 개의 박스가 남는다. 한 물체에는 박스가 하나만 있어야 하므로, 같은 물체를 가리키는 박스들 중 하나만 남기고 나머지는 지워야 한다. 이를 NMS라고 한다. 두 박스가 같은 물체를 가리키는지는 IoU로 판단하며, IoU가 크면 두 박스가 같은 물체를 가리키는 것으로 본다.

NMS (Non-Maximum Suppression, 비최대 억제)

겹치는 예측 박스 가운데 신뢰도가 가장 높은 것만 남기고 나머지를 지우는 절차.

  1. 남은 박스 가운데 신뢰도가 가장 높은 박스를 채택한다
  2. 채택한 박스와 IoU가 0.5 이상인 박스를 모두 지운다
  3. 남은 박스가 없을 때까지 1~2를 반복한다

예를 들어 다음과 같이 후보 박스 다섯 개가 있고, 신뢰도가 높은 순서가 B1(0.95), B4(0.90), B2(0.80), B5(0.70), B3(0.60)이라고 하자.

단계 채택하는 박스 채택한 박스와의 IoU 지우는 박스
1 B1 (0.95) B2 0.72, B3 0.64, B4 0.00, B5 0.00 B2, B3
2 B4 (0.90) B5 0.56 B5
결과 B1, B4

NMS 결과 자동차에는 B1, 사람에는 B4가 하나씩 남는다. B1과 B4는 IoU가 0이므로 서로 다른 물체를 가리키는 박스로 보고 둘 다 남긴다.

예측의 정답 판정

NMS까지 거친 박스가 탐지 모델의 최종 출력이므로, 모델의 성능을 평가하려면 이 박스들이 맞았는지를 판정해야 한다. 탐지에서는 클래스뿐 아니라 위치도 맞아야 하므로, 예측 박스와 정답 박스의 IoU가 0.5 이상이고 클래스도 같을 때 맞은 예측으로 본다. 예를 들어 다음 세 예측은 아래 표와 같이 판정된다.

예측 정답 IoU 판정
자동차 자동차 0.73 맞음
사람 사람 0.12 틀림
자동차 사람 0.79 틀림

두 번째 예측은 클래스는 맞았지만 IoU가 0.12로 0.5보다 작으므로 틀린 예측이다. 세 번째 예측은 IoU가 0.79로 박스는 거의 맞았지만 사람을 자동차로 예측했으므로 역시 틀린 예측이다.

탐지 모델의 전이 학습

탐지 모델도 8장의 분류 모델과 같이 전이 학습을 사용할 수 있다. 탐지 모델을 처음부터 학습시키려면 박스 레이블이 달린 이미지가 매우 많이 필요하므로, 대량의 데이터로 사전 학습된 탐지 모델을 가져와 사용한다. 탐지 모델의 사전 학습에 널리 쓰이는 데이터셋으로는 COCO가 있다. COCO는 약 12만 장의 이미지에 80개 클래스의 박스를 그려 둔 데이터셋으로, 이 데이터로 학습된 탐지 모델이 공개되어 있다. 따라서 내가 가진 이미지 수백 장에 박스를 그려 이 모델을 미세 조정하면, 내가 원하는 물체를 찾는 탐지 모델을 만들 수 있다.

대표적인 객체탐지 모델

지금까지 설명한 바운딩 박스, 신뢰도, 레이블 할당, 손실, NMS는 대부분의 객체탐지 모델에 공통으로 쓰이는 개념이며, 모델마다 후보 박스를 만드는 방식과 네트워크의 구조가 다르다. 객체탐지 모델은 후보 영역을 먼저 찾은 뒤 영역마다 분류하는 2단계 방식과, 이미지 전체에서 박스와 클래스를 한 번에 출력하는 1단계 방식으로 나뉜다. 대표적인 객체탐지 모델은 다음과 같다.

모델 발표 방식 특징
R-CNN 2014 2단계 후보 영역을 먼저 찾고 영역마다 CNN으로 분류하는 방식의 시작
Faster R-CNN 2015 2단계 후보 영역을 찾는 과정까지 신경망으로 학습하여 속도를 높임
YOLO 2016 1단계 이미지를 한 번만 보고(You Only Look Once) 모든 박스를 한꺼번에 출력하며, 이후 여러 버전으로 계속 개선됨
SSD 2016 1단계 크기가 다른 여러 특성 맵에서 박스를 출력하여 크고 작은 물체를 함께 찾음
RetinaNet 2017 1단계 배경 박스가 지나치게 많은 문제를 손실 함수(Focal Loss)로 줄임
DETR 2020 1단계 11장에서 다룰 트랜스포머를 이용하여 NMS 없이 박스를 직접 출력

이 중 YOLO는 속도가 빨라 실시간 탐지가 필요한 자율주행, CCTV 등에서 널리 쓰이며, 앞에서 본 COCO로 사전 학습된 가중치가 공개되어 있어 전이 학습에도 많이 사용된다.
