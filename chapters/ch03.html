딥러닝의 학습

학습 목표
  • 학습이 “전체 손실이 가장 작아지는 가중치를 찾는 과정”임을 설명할 수 있다
  • 순전파로 예측값을 계산하고, 제곱오차·교차 엔트로피로 손실을 직접 계산할 수 있다
  • 전체 손실(MSE, 교차 엔트로피 평균)을 계산할 수 있다
  • Softmax의 역할과 계산 과정을 안다
  • 손실함수 \(J(W)\)가 가중치의 함수임을 이해하고, 좋은 가중치를 \(\operatorname{argmin}\)으로 쓸 수 있다
  • 손실함수를 가중치로 미분·편미분하여 기울기를 구할 수 있다
  • 경사하강법으로 가중치를 한 스텝씩 갱신하여 최솟값에 도달하는 과정을 따라갈 수 있다

학습이란 무엇인가

앞 장에서 인공신경망의 구조를 만들었다. 노드와 아크를 그리고, 아크마다 가중치가 붙는다는 것까지 정했다. 그런데 그 가중치 값은 누가 정하는가? 이 장의 주제다.

학습 (Learning)

주어진 데이터에 대해 전체 손실이 가장 작아지는 가중치를 찾아 나가는 과정.

  • 데이터: 주어지는 것
  • 가중치: 데이터를 통해 학습하는 것

1장에서 “오차가 가장 작아지는 파라미터를 찾는 과정”이라 한 것과 같은 말이다. 이 장에서는 그 오차를 신경망에 맞게 정확히 정의하고, 찾아 나가는 방법을 배운다.

이 장은 네 가지 질문에 차례로 답한다.

  1. 데이터 한 건이 얼마나 틀렸는지 어떻게 숫자로 만드나 → 손실
  2. 데이터 전체로는 어떻게 합치나 → 전체 손실
  3. 어떤 가중치가 좋은 가중치인가 → 손실함수의 최소화
  4. 그 가중치를 어떻게 찾나 → 미분과 경사하강법. 이 장의 후반은 예제 하나를 잡고 최솟값에 도달할 때까지 한 스텝씩 따라간다

예제 데이터는 다음과 같다.

  • \(x_1\): 참여한 수업의 개수
  • \(x_2\): 기말 프로젝트에 투자한 시간
  • \(y\): 기말 점수 (%) → 실수이므로 회귀 문제
코드 
import pandas as pd

score_data = pd.DataFrame({
    '학생': [1, 2, 3],
    '$x_1$ 수업 참여 수': [4, 2, 5],
    '$x_2$ 프로젝트 시간': [5, 1, 8],
    '$y$ 기말 점수': [90, 20, 95],
})
score_data.to_html(index=False, border=0, escape=False)

순전파: 현재 가중치로 예측하기

학습을 시작하기 전, 가중치에는 아무 값이나 들어 있다. 그 상태의 신경망은 무엇을 내놓는가?

순전파 (Forward Pass)

입력노드에 데이터 한 건을 넣고, 왼쪽 층부터 차례로 합과 활성화를 계산해 출력노드까지 값을 흘려보내는 것. 앞 장에서 XOR을 계산할 때 한 일이 순전파다.

  • 순전파의 결과, 출력노드에 나온 값이 예측값 \(\hat{y}\)다
  • 데이터에 기록되어 있는 정답이 실제값 \(y\)다

입력노드 2개, 은닉노드 3개, 출력노드 1개로 인공신경망을 구성한다. 점수는 실수이므로 출력노드의 활성화 함수는 항등 함수 \(g(z) = z\)다. 은닉노드의 활성화 함수는 Sigmoid로 둔다.

현재 가중치가 다음과 같이 들어 있다고 하자. 학습 전이므로 아무 값이나 들어 있는 상태다. 앞 장처럼 아크 위에 가중치를 적는다. 색은 도착하는 노드별로 구분했다.

노드별로 합을 쓰면 다음과 같다. 각 노드로 들어오는 아크의 가중치를 그대로 옮긴 것이다.

  • \(z_1\) (빨강): 합 \(= -5.2 - 0.8\,x_1 + 1.4\,x_2\), 활성화 Sigmoid
  • \(z_2\) (파랑): 합 \(= 3.9 - 0.2\,x_1 - 1.5\,x_2\), 활성화 Sigmoid
  • \(z_3\) (초록): 합 \(= 0.7 - 0.8\,x_1 + 0.4\,x_2\), 활성화 Sigmoid
  • \(\hat{y}\) (보라): 합 \(= -10 + 72.5\,z_1 + 73.7\,z_2 + 65.6\,z_3\), 활성화 항등

첫 번째 학생 \(x^{(1)} = [4, 5]\)를 입력노드에 넣고 순전파한다.

손실: 한 건이 얼마나 틀렸나

손실 (Loss)

데이터 한 건에 대해, 예측값 \(\hat{y}\)와 실제값 \(y\)의 차이를 숫자 하나로 나타낸 값. 데이터 한 건마다 손실이 하나씩 나온다.

\(i\)번째 데이터의 손실을 \(\mathcal{L}\big(\hat{y}^{(i)}, y^{(i)}\big)\)로 쓴다. 클수록 많이 틀린 것이다.

차이를 숫자로 만드는 식은 문제 유형에 따라 다르다. 회귀에서는 제곱오차를 쓴다.

제곱오차 (Squared Error)

\[\mathcal{L}(\hat{y}, y) = (y - \hat{y})^2\]

회귀 문제에서 손실을 계산하는 식. 1장에서 잔차를 제곱했던 것과 같다. 부호를 없애고, 크게 틀릴수록 더 크게 벌한다.

학생 1의 손실은

\[\mathcal{L} = (90 - 30)^2 = 3600\]

이다. 여기서 한 가지를 눈여겨보자. 가중치가 달랐으면 순전파 결과 \(\hat{y}\)가 달랐고, 손실도 달랐을 것이다. 손실은 신경망의 가중치에 의해 결정된다.

학생은 세 명이다. 한 건씩 손실을 구했으면, 전체로는 얼마나 틀린 것인가?

전체 손실: 데이터 전체가 얼마나 틀렸나

전체 손실

학습 데이터 모든 건의 손실을 평균한 값.

\[J = \frac{1}{n} \sum_{i=1}^{n} \mathcal{L}\big(\hat{y}^{(i)}, y^{(i)}\big)\]

현재 가중치가 주어진 데이터를 얼마나 잘 나타내고 있는지를 숫자 하나로 요약한다. 제곱오차의 평균은 평균제곱오차(MSE, Mean Squared Error)라 부른다. (영어 자료에서는 Empirical Loss라고도 쓴다.)

학생 2와 3도 같은 가중치로 순전파한다. 절차는 학생 1과 똑같다.

예측 \(\hat{y} = [30, 80, 85]\), 실제 \(y = [90, 20, 95]\)다. 세 손실을 구해 평균한다.

코드 
import numpy as np
import pandas as pd

preds = [30, 80, 85]
actual = [90, 20, 95]

rows = []
for i, (p, y) in enumerate(zip(preds, actual), start=1):
    rows.append({'학생': i, 'ŷ (Predicted)': p, '$y$ (Actual)': y,
                 '$y - \\hat{y}$': y - p, '손실 $(y - \\hat{y})^2$': (y - p) ** 2})
mse = np.mean([(y - p) ** 2 for p, y in zip(preds, actual)])
rows.append({'학생': '평균', 'ŷ (Predicted)': '', '$y$ (Actual)': '', '$y - \\hat{y}$': '전체 손실 $J$',
             '손실 $(y - \\hat{y})^2$': f'<b>{mse:.1f}</b>'})
pd.DataFrame(rows).to_html(index=False, border=0, escape=False)

확률을 출력하기

확률 출력 (Sigmoid 출력층)

분류 문제에서는 특정 카테고리에 소속될 확률을 예측하는 것이 자연스럽다. 출력노드의 활성화 함수를 항등 함수에서 Sigmoid로 바꾸면 출력이 항상 0과 1 사이가 되고, 이것을 합격할 확률로 읽는다.

\[\hat{y} = \sigma(z) = \frac{1}{1 + e^{-z}}, \qquad 0 < \hat{y} < 1\]

구조는 회귀 때와 같고 출력노드의 활성화 함수만 다르다. 가중치는 이 문제에 맞게 따로 들어 있어야 한다. 그 신경망에서 학생 1을 순전파했을 때 출력노드의 합이 \(-2.15\)였다면 \(\hat{y} = \sigma(-2.15) = 0.104\), 합격 확률 약 0.1이다. 실제값은 합격(1)이다.

합이 어떤 값이어도 Sigmoid를 통과하면 0과 1 사이가 되는지 직접 확인한다. 슬라이더로 \(z\)를 움직이거나, 칸에 아주 큰 값이나 아주 작은 값을 넣어 보자.

교차 엔트로피

실제값은 0 또는 1, 예측값은 확률이다. 이때 손실을 계산하는 식이 교차 엔트로피다.

교차 엔트로피 (Cross Entropy)

\[\mathcal{L}(\hat{y}, y) = -\Big[\, y \log \hat{y} + (1 - y) \log (1 - \hat{y}) \,\Big]\]

\(y\)는 0 또는 1이므로 대괄호 안의 두 항 중 하나만 살아남는다.

  • \(y = 1\)이면: \(\mathcal{L} = -\log \hat{y}\). 합격 확률을 높게 말했을수록 손실이 작다
  • \(y = 0\)이면: \(\mathcal{L} = -\log (1 - \hat{y})\). 합격 확률을 낮게 말했을수록 손실이 작다

제곱오차 대신 이 식을 쓰는 이유는, 확률이 정답에서 멀어질수록 손실이 급격히 커져 확신에 찬 오답을 크게 벌하기 때문이다. 아래 보드에서 확인한다.

학생 2와 3의 합격 확률도 각각 0.8, 0.6이 나왔다고 하자. 예측 \(\hat{y} = [0.1, 0.8, 0.6]\), 실제 \(y = [1, 0, 1]\)이다.

다중 분류의 손실: Softmax와 다중 클래스 교차 엔트로피

클래스가 셋 이상인 문제를 다중 분류(multi-class classification)라 한다. 예를 들어 주어진 이미지를 고양이, 강아지, 소 중 하나로 분류하는 문제다.

  • 실제값 \(y\): \([\text{고양이}(1),\ \text{강아지}(0),\ \text{소}(0)]\) → 고양이가 정답. 정답 자리만 1인 이런 표현을 원-핫(one-hot)이라 한다
  • 예측값 \(\hat{y}\): \([\text{고양이}(0.8),\ \text{강아지}(0.1),\ \text{소}(0.1)]\) → 고양이로 분류될 확률이 높음

출력노드가 클래스 수만큼 3개 필요하고, 세 출력의 합이 1이 되어야 확률로 읽을 수 있다.

Softmax

Softmax 함수

출력노드가 \(K\)개일 때, 각 노드의 합 \(z_1, \ldots, z_K\)를 합이 1인 확률로 바꾸는 활성화 함수.

\[S(z_k) = \frac{e^{z_k}}{\sum_{j=1}^{K} e^{z_j}}\]

각 클래스로 구별될 확률을 계산하기 위해 출력층에서 사용한다. \(e^{z}\)는 항상 양수이므로 모든 확률이 양수이고, 분모가 분자들의 합이므로 전체 합은 1이다.

세 출력노드의 합이 \(z = [2.0,\ 1.0,\ 0.1]\)이라 하자.

다중 클래스 교차 엔트로피

다중 클래스 교차 엔트로피 (Categorical Cross Entropy)

\(i\)번째 데이터의 손실은

\[\mathcal{L}_i = -\sum_{j=1}^{K} t_{i,j} \log p_{i,j}\]

\(p_{i,j}\)는 Softmax가 낸 \(j\)번째 클래스의 확률, \(t_{i,j}\)는 원-핫 실제값(\(j\)가 정답이면 1, 아니면 0)이다. 정답 자리만 1이므로 결국 정답 클래스의 확률에 \(-\log\)를 취한 값 하나만 남는다. 앞 절 교차 엔트로피의 확장이다.

네 장의 이미지에 대한 예측 확률과 원-핫 실제값이 다음과 같다.

코드 
import numpy as np
import pandas as pd

P = [[0.8, 0.1, 0.1], [0.2, 0.7, 0.1], [0.3, 0.3, 0.4], [0.9, 0.1, 0.1]]
T = [[1, 0, 0], [0, 1, 0], [0, 1, 0], [1, 0, 0]]
names = ['고양이', '강아지', '소']

rows, losses = [], []
for i, (p, t) in enumerate(zip(P, T), start=1):
    j = t.index(1)
    L = -np.log(p[j]); losses.append(L)
    rows.append({'이미지': i, 'ŷ = [고양이, 강아지, 소]': str(p), '$y$ (원-핫)': str(t),

좋은 가중치란 무엇인가

여기서부터는 회귀 예제(기말 점수)로 돌아간다. 손실이 제곱오차라 계산이 가장 단순하기 때문이다. 상황을 다시 적으면 다음과 같다.

  • 현재 가중치로 순전파한 예측: \(\hat{y} = [30, 80, 85]\)
  • 실제값: \(y = [90, 20, 95]\)
  • 전체 손실(MSE): 2,433

이 2,433은 지금 가중치의 성적표다. 가중치를 바꾸면 이 숫자는 어떻게 되는가? 가장 단순한 실험을 해 보자. 출력노드의 편향 \(w_0 = -10\)만 바꾸고 다른 가중치 12개는 그대로 둔다. 출력노드의 활성화가 항등 함수이므로, 편향을 3 올리면 세 학생의 예측이 모두 3점씩 올라간다.

코드 
import numpy as np
import pandas as pd

actual = np.array([90, 20, 95])
base = np.array([30, 80, 85])          # w0 = −10일 때의 예측

rows = []
for w0, note in [(-10, '현재'), (-7, '+3'), (0, '+10')]:
    preds = base + (w0 + 10)           # 항등 출력이므로 편향 변화가 그대로 예측에 더해진다
    J = np.mean((actual - preds) ** 2)
    rows.append({'출력노드 편향 $w_0$': f'{w0} ({note})', 'ŷ = [학생 1, 2, 3]': str(preds.astype(int).tolist()),
                 '$y$': str(actual.tolist()), '전체 손실 $J$': f'{J:,.1f}'})
pd.DataFrame(rows).to_html(index=False, border=0, escape=False)

편향을 3 올리면 전체 손실이 2,422로 줄고, 10 올리면 2,467로 는다. 가중치 하나만 바꿔도 전체 손실이 달라진다. 데이터는 고정되어 있고 변하는 것은 가중치뿐이다. 그러므로 전체 손실은 가중치의 함수다.

편향을 움직이며 전체 손실 보기

표는 세 값만 보였다. 편향 \(w_0\)를 연속으로 움직이면 전체 손실이 어떤 모양으로 변하는지 본다.

손실함수 (Loss Function) \(J(W)\)

전체 손실을 가중치 \(W\)의 함수로 본 것. \(W\)를 넣으면 그 가중치에서의 전체 손실이 나온다.

\[J(W) = \frac{1}{n} \sum_{i=1}^{n} \mathcal{L}\big(f(x^{(i)}; W),\ y^{(i)}\big)\]

\(f(x^{(i)}; W)\)는 “가중치가 \(W\)인 신경망에 \(x^{(i)}\)를 넣어 순전파한 결과”, 즉 \(\hat{y}^{(i)}\)다. \(W\)는 신경망의 모든 가중치와 편향을 묶어 쓴 기호다. (최적화의 대상이 되는 함수라는 뜻에서 목적함수(objective function)라고도 한다.)

손실 최소화

가장 좋은 가중치 \(W^*\)는 손실함수를 최소로 만드는 가중치다.

\[W^* = \underset{W}{\operatorname{argmin}}\ J(W)\]

\(\operatorname{argmin}\)은 “함수값을 최소로 만드는 입력”이다. 학습은 이 \(W^*\)를 찾는 과정이다.

위 그릇의 바닥이 어디인지 눈으로는 대략 보인다. 하지만 컴퓨터는 그래프를 보지 못한다. 가중치가 13개면 사람도 그래프를 그릴 수 없다. 그래프 없이, 지금 서 있는 자리에서 어느 쪽으로 가야 낮아지는지 알아내는 방법이 필요하다. 그것이 미분이다. 손실함수는 잠시 내려놓고, 간단한 함수로 도구부터 준비한다. 도구가 갖춰지면 손실함수로 돌아온다.

미분: 어느 쪽으로 움직여야 하나

미분 (Derivative)

\(x\)값의 변화에 따라 \(y\)값이 얼마나 민감하게 변하는지 숫자로 표현한 것. 한 점에서의 순간의 기울기다.

\[\frac{dy}{dx} = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x}\]

\(x\)를 아주 조금(\(\Delta x\)) 움직였을 때 \(y\)가 얼마나 변했는지(\(\Delta y\))의 비율이고, 그래프 위 그 점에서 그은 접선의 기울기와 같다.

식으로도 간단히

\(f(w) = (w - 3)^2\)을 보자. 그릇 모양이고 바닥은 \(w = 3\)이다. 이 수업에서 필요한 미분 공식은 두 개뿐이다.

  • \(\dfrac{d}{dw}\,w^2 = 2w\)
  • \(\dfrac{d}{dw}\,(w - a)^2 = 2(w - a)\)   (\(a\)는 상수)

두 번째 공식으로 \(f'(w) = 2(w - 3)\)이다. 세 지점에서 값을 구한다.

위치 \(w\) 미분값 \(f'(w) = 2(w-3)\) 뜻 할 일
\(1\) \(-4\) \(w\)를 늘리면 \(f\)가 작아진다 \(w\)를 늘린다 (오른쪽으로)
\(5\) \(+4\) \(w\)를 늘리면 \(f\)가 커진다 \(w\)를 줄인다 (왼쪽으로)
\(3\) \(0\) 평평하다 바닥. 멈춘다

미분값의 부호가 갈 방향을, 크기가 얼마나 급한지를 알려 준다. 그래프를 보지 않고 식만으로 알 수 있다.

경사하강법: 기울기의 반대 방향으로 조금씩

미분값의 부호로 방향을 읽는 것은 직관이다. 알고리즘으로 만들려면 명제가 필요하다.

명제

\(\eta > 0\)가 충분히 작으면, \(w \leftarrow w - \eta\, f'(w)\)로 갱신할 때 함수값은 감소하거나 같다. 같아지는 것은 \(f'(w) = 0\)인 점에서만이다.

학습률 (Learning Rate) \(\eta\)

갱신식 \(w \leftarrow w - \eta\, f'(w)\)에서 기울기에 곱하는 작은 양수. 기울기는 방향과 급한 정도를 알려 주고, 한 번에 얼마나 이동할지는 \(\eta\)가 정한다. 학습 전에 사람이 정하는 값이다(하이퍼파라미터). 어떻게 고르는지는 다음 장에서 다룬다.

근거.

  1. 접선 근사. \(\Delta\)가 작으면 \[f(w+\Delta) - f(w) \approx f'(w)\,\Delta\]

  2. 이동량을 미분값의 반대 부호로 잡는다. \[\Delta = -\eta\, f'(w), \qquad \eta > 0\]

  3. 2를 1에 대입한다. \[f(w+\Delta) - f(w) \approx f'(w) \cdot \big(-\eta\, f'(w)\big) = -\eta\,[f'(w)]^2\] \(f'(w)\)가 두 번 곱해진 것은 1의 기울기와 2의 기울기가 만났기 때문이다.

  4. 부호를 본다. \[[f'(w)]^2 \ge 0 \quad\Longrightarrow\quad f(w+\Delta) - f(w) \le 0\] 등호는 \(f'(w) = 0\)일 때만이다.

  5. 1은 \(\Delta\)가 작을 때만 성립하므로, \(\eta\)가 충분히 작아야 한다는 조건이 붙는다.

그러므로 조금 가서 다시 미분하고, 또 조금 가고를 반복하면 함수값은 계속 줄어들고, 미분값이 0이 되는 바닥에서 멈춘다. 이것이 경사하강법이다.

경사하강법 (Gradient Descent)

아무 위치에서 시작해, 기울기를 계산하고 그 반대 방향으로 조금 이동하는 일을 함수값이 더 줄지 않을 때까지 반복하는 알고리즘.

  1. 초기 위치를 무작위로 정한다
  2. 다음 과정을 더 이상 개선되지 않을 때까지 반복한다
    • (1) 기울기 계산. \(f'(w)\). 현재 위치에서 함수값이 가장 빠르게 증가하는 방향이다
    • (2) 반대 방향으로 이동. \(w \leftarrow w - \eta\, f'(w)\)
  3. (3) 수렴하면 최종 위치를 리턴한다
수렴 (Convergence)

반복해도 함수값이 더 줄지 않는 상태. 이때 최솟값에 도달했다고 판단하고 멈춘다. (정말 최솟값일까? 이 질문은 이 장 끝에서 다시 본다)

편미분

편미분 (Partial Derivative)

변수가 여러 개인 함수에서, 한 변수를 제외한 나머지를 상수로 간주하여 미분하는 것. \(w_0\)에 대한 편미분은 \(\dfrac{\partial f}{\partial w_0}\)로 쓴다.

\(w_0\)로 편미분할 때 \(3(w_1 - 1)^2\)은 상수라 사라지고, \(w_1\)로 편미분할 때 \((w_0 - 2)^2\)이 사라진다.

\[\frac{\partial f}{\partial w_0} = 2(w_0 - 2), \qquad \frac{\partial f}{\partial w_1} = 6(w_1 - 1)\]

기울기 (Gradient)

각 변수에 대한 편미분을 좌표로 갖는 벡터.

\[\nabla f = \left( \frac{\partial f}{\partial w_0},\ \frac{\partial f}{\partial w_1} \right)\]

점 \((-1, 3.5)\)에서는 \(\nabla f = (-6,\ 15)\)다.

✍️ 직접 해보기 — 편미분 연습

\(f(x_1, x_2) = 3x_1^4 + 2x_1^2 x_2^2 + 7x_2^4\)를 편미분하고, \((x_1, x_2) = (1, 2)\)에서 기울기 벡터를 구하라. 정답을 보기 전에 손으로 먼저 계산하라.

\(\dfrac{\partial f}{\partial x_1} = 12x_1^3 + 4x_1 x_2^2\), \(\quad \dfrac{\partial f}{\partial x_2} = 4x_1^2 x_2 + 28x_2^3\), \(\quad \nabla f(1, 2) = (28, 232)\)

기울기는 가장 빨리 커지는 방향

1차원의 명제가 그대로 확장된다. \((w_0, w_1)\)에서 \(\Delta = (\Delta_0, \Delta_1)\)만큼 움직였을 때의 변화량은

\[f(w + \Delta) - f(w) \approx \frac{\partial f}{\partial w_0}\Delta_0 + \frac{\partial f}{\partial w_1}\Delta_1 = \nabla f \cdot \Delta\]

기울기와 이동의 내적이다. 이동 거리를 고정하면 내적은 \(\Delta\)가 \(\nabla f\)와 같은 방향일 때 최대, 반대 방향일 때 최소다. 그러므로 \(\nabla f\)는 가장 빨리 커지는 방향이고, \(\Delta = -\eta\,\nabla f\)로 두면 변화량은 \(-\eta\,|\nabla f|^2 \le 0\)이다.

손실함수에서는 편미분

우리 예제의 손실함수 \(J(W)\)는 가중치 13개의 함수다. 하는 일은 지금 본 것과 같다. 각 가중치로 편미분해 13개를 모으면 기울기 \(\nabla J\)이고, 그 반대 방향으로 13개를 동시에 조금씩 움직인다. 2차원에서 되는 것이 13차원에서도 된다. 그림만 못 그릴 뿐이다.

손실함수도 같은 방식으로

도구가 갖춰졌다. 함수가 무엇이든, 편미분할 수 있으면 경사하강법으로 바닥을 찾는다. 우리 예제 신경망으로 돌아가서, 가중치 13개를 전부 경사하강법으로 움직여 보자. 시작은 지금까지 쓴 가중치(전체 손실 2,433)다.

코드 
import numpy as np
import pandas as pd

X, Y = EX_X, EX_Y
b, Wh, c0, co = EX_B.copy(), EX_W.copy(), EX_W0, EX_WO.copy()
eta, hist = 0.001, []
for k in range(2001):
    H = SIG(b + X @ Wh.T)
    pred = c0 + H @ co
    r = Y - pred
    hist.append({'step': k, 'J': float(np.mean(r ** 2)), 'pred': pred.copy()})
    d = -2/3 * r                                  # ∂J/∂ŷ (학생별)
    dH = np.outer(d, co) * H * (1 - H)            # 은닉층까지 전달된 기울기 (역전파, 4장)
    c0 -= eta * d.sum();      co -= eta * (d @ H)         # 출력층 편향·가중치 4개
    b  -= eta * dH.sum(0);    Wh -= eta * (dH.T @ X)      # 은닉층 편향·가중치 9개

실제 손실함수의 지형도

이 장의 예제는 손실함수가 매끈한 그릇 모양이었다. 어디서 출발해도 바닥 하나로 모인다. 실제 신경망의 손실함수는 가중치가 수백만 개인 공간 위의 울퉁불퉁한 산맥이다. 골짜기가 여러 개 있고(지역 최솟값), 평평한 고원도 있고, 좁고 가파른 협곡도 있다.

그래서 “수렴하면 최솟값에 도달했다고 판단한다”고 했지만, 그것이 가장 낮은 골짜기라는 보장은 없다. 최적화를 찾는 것은 어려운 과정이고, 어디서 출발하는지(초기 가중치), 한 번에 얼마나 움직이는지(학습률), 기울기를 어떤 데이터로 계산하는지(배치)가 결과를 바꾼다. 이 문제들이 다음 장의 주제다.

개념 핵심 내용
학습 전체 손실이 가장 작아지는 가중치를 찾는 과정. 데이터는 주어지고 가중치를 찾는다
순전파 입력 → 왼쪽 층부터 계산 → 예측값 \(\hat{y}\). 실제값 \(y\)와 비교
손실 한 건이 틀린 정도. 회귀는 제곱오차 \((y-\hat{y})^2\)
전체 손실 모든 건의 손실 평균. 제곱오차의 평균이 MSE
교차 엔트로피 분류의 손실. 출력은 Sigmoid 확률. \(y=1\)이면 \(-\log\hat{y}\), \(y=0\)이면 \(-\log(1-\hat{y})\)
Softmax \(e^{z_k}/\sum e^{z_j}\). 출력 \(K\)개를 합이 1인 확률로. 다중 클래스 교차 엔트로피 = 정답 확률의 \(-\log\)
손실함수 \(J(W)\) 전체 손실을 가중치의 함수로 본 것. 좋은 가중치 \(W^* = \operatorname{argmin}_W J(W)\)
미분 한 점에서의 순간의 기울기(접선). 부호가 방향, 크기가 급한 정도. \((w-a)^2 \to 2(w-a)\)
