학습 목표

  • 셀프 어텐션을 거친 새 벡터로 다음 단어의 확률을 계산하고, 단어를 하나씩 이어 붙여 문장을 만드는 절차를 설명한다

트랜스포머는 2017년 논문 “Attention Is All You Need”에서 처음 제시된 신경망이고, 지금의 ChatGPT도 이 구조 위에 만들어졌다. ChatGPT 같은 언어 모델이 하는 일은 지금까지 쓴 문장을 받아 다음에 올 단어를 맞히는 것인데, 트랜스포머는 그 일을 하기 위해 문장 속 단어들이 서로의 정보를 주고받게 한다. 이 장에서는 짧은 문장 하나를 숫자로 따라가며 그 계산을 하나씩 해 보고, 계산의 결과로 다음 단어를 예측하는 데까지 간다.

ch11 = {
  const words = ["the", "dog", "ate", "its", "food"];
  const vocab = ["the", "dog", "ate", "its", "food", "."];
  const X = [[1, 9], [9, 1], [2, 4], [5, 8], [4, 2]];
  const WQ = [[0.4, 0], [0, 0.3]];
  const WK = [[0, 0.3], [0.1, 0]];
  const WV = [[0.5, -0.4], [0, 0.4]];
  const WU = [[0, 0, 0, 0, 0.3, 0], [0, 0, 0.1, 0, -0.1, -0.1]];
  // 본문의 손계산과 같도록, 단계마다 소수 둘째 자리에서 반올림한 값을 다음 단계에 쓴다
  const r2 = x => Math.sign(x) * Math.round(Math.abs(+x.toFixed(6)) * 100 + 1e-7) / 100 + 0;
  const mm = (A, B) => A.map(a => B[0].map((_, j) => +a.reduce((s, v, i) => s + v * B[i][j], 0).toFixed(4)));
  const Q = mm(X, WQ), K = mm(X, WK), V = mm(X, WV);
  const QK = Q.map(q => K.map(k => r2(q[0] * k[0] + q[1] * k[1])));
  const S = QK.map(row => row.map(v => r2(v / Math.SQRT2)));
  const E = S.map(row => row.map(v => r2(Math.exp(v))));
  const soft = (row, ok) => { const e = row.map((v, j) => ok(j) ? Math.exp(v) : 0); const s = e.reduce((a, b) => a + b, 0); return e.map(v => r2(v / s)); };
  const A = S.map(row => soft(row, () => true));
  const AM = S.map((row, i) => soft(row, j => j <= i));
  const mix = P => P.map(p => [0, 1].map(k => r2(p.reduce((s, a, j) => s + a * V[j][k], 0))));
  const Z = mix(A), ZM = mix(AM);
  // 가져온 내용은 임베딩과 같은 2차원이므로 그대로 더해 새 벡터를 만든다
  const XN = X.map((x, i) => x.map((v, m) => r2(v + Z[i][m])));
  const XNM = X.map((x, i) => x.map((v, m) => r2(v + ZM[i][m])));
  const scoreOf = x => vocab.map((_, j) => r2(x[0] * WU[0][j] + x[1] * WU[1][j]));
  const probOf = sc => { const e = sc.map(v => r2(Math.exp(v))); const s = e.reduce((a, b) => a + b, 0); return e.map(v => r2(v / s)); };
  const score = scoreOf(XNM[3]), score0 = scoreOf(X[3]);
  return {words, vocab, X, WQ, WK, WV, WU, Q, K, V, QK, S, E, A, AM, Z, ZM, XN, XNM, score, score0,
          prob: probOf(score), prob0: probOf(score0), r2};
}

단어 벡터는 문맥을 모른다

10장에서는 임베딩 행렬에서 단어의 행 하나를 꺼내 그 단어의 벡터로 썼다. 이 벡터는 단어마다 하나로 정해져 있으므로, 같은 단어는 어느 문장에 나오든 같은 벡터가 된다. 다음 세 문장에 나오는 mole을 보자.

문장 mole의 뜻
American shrew mole 두더지
One mole of carbon dioxide 몰(물질의 양)
Take a biopsy of the mole 피부의 점

세 mole은 뜻이 전혀 다르지만 철자가 같으므로 임베딩 행렬에서 같은 행을 꺼내고, 셋 모두 같은 벡터가 된다. 사람은 앞뒤 단어를 보고 어떤 뜻인지 바로 알지만, 임베딩 벡터만으로는 셋을 구별할 수 없다.

뜻이 여러 개인 단어만 그런 것은 아니다. 이 장에서 계속 쓸 문장을 보자.

The dog ate its food.

여기서 its는 dog의 것이라는 뜻이다. 그런데 “The cat ate its food.”에서는 cat의 것이 된다. its의 임베딩 벡터는 두 문장에서 똑같으므로, 벡터만 보아서는 누구의 것인지 알 수 없다. 단어가 문장에서 갖는 뜻을 나타내려면 문장 속의 다른 단어를 보고 벡터를 고쳐 써야 하고, its라면 dog의 정보를 가져와 ’dog의’라는 뜻을 담은 벡터로 바뀌어야 한다. 이 일을 하는 계산이 셀프 어텐션이다.

셀프 어텐션 (Self-Attention)

문장 속 단어들 사이의 연관도를 계산하고, 그 연관도만큼 다른 단어의 정보를 가져와 각 단어의 벡터를 문맥에 맞게 고쳐 쓰는 계산. 같은 문장 안의 단어끼리 서로를 보므로 ’셀프’라는 말이 붙는다.

예문의 다섯 단어를 2차원 임베딩 벡터로 바꾸고, 이 다섯 벡터를 위에서부터 차례로 쌓은 5×2 행렬을 \(X\)라고 하자. 벡터가 2차원이므로 10장에서처럼 단어 하나를 평면의 점 하나로 그릴 수 있다. 실제 임베딩은 수백 차원이 넘지만 계산하는 방법은 2차원일 때와 같다.

its의 임베딩은 이 문장에서도 “The cat ate its food.”에서도 같으므로, 평면에서도 같은 점이다. 셀프 어텐션이 하는 일을 이 평면에서 말하면 its의 점을 문장에 맞는 자리로 옮기는 것이고, 이 문장이라면 its를 dog의 정보를 담은 자리로 옮겨야 한다.

이제 its의 점이 옮겨 가는 과정을 숫자로 따라가 보자. 먼저 단어마다 벡터를 세 개 만들고, 그중 두 벡터로 어느 단어에서 정보를 얼마나 가져올지 비율을 정한 뒤, 그 비율대로 나머지 한 벡터를 섞어 its의 임베딩 벡터에 더한다. 이 계산은 모두 행렬 곱이어서 다섯 단어의 계산이 한꺼번에 이루어지므로, 아래에서는 행렬 곱을 하나씩 그림으로 본다.

Query, Key, Value

한 단어가 다른 단어의 정보를 가져오려면, 자기가 무엇을 찾는지와 다른 단어가 그 물음에 답이 될 수 있는지를 견주어 볼 수 있어야 하고, 실제로 가져갈 내용도 있어야 한다. 그래서 셀프 어텐션은 단어마다 벡터를 세 개 만든다.

Query, Key, Value

단어의 임베딩 벡터에 서로 다른 가중치 행렬 \(W_Q\), \(W_K\), \(W_V\)를 곱해 얻는 세 벡터.

  • Query: 이 단어가 다른 단어들에게서 찾는 것
  • Key: 다른 단어의 Query에 답이 될 수 있는 것
  • Value: 이 단어에서 실제로 가져갈 내용

세 가중치는 원래 학습으로 정해지고 음수가 될 수도 있지만, 여기서는 다음과 같이 상정하자.

\[W_Q = \begin{bmatrix} 0.4 & 0 \\ 0 & 0.3 \end{bmatrix}, \qquad W_K = \begin{bmatrix} 0 & 0.3 \\ 0.1 & 0 \end{bmatrix}, \qquad W_V = \begin{bmatrix} 0.5 & -0.4 \\ 0 & 0.4 \end{bmatrix}\]

세 행렬 모두 2차원 임베딩 벡터를 2차원 벡터로 바꾸므로 2×2다. Query와 Key의 차원은 \(d_k\)로 쓰며, 여기서는 \(d_k = 2\)다. 다섯 단어를 쌓은 \(X\)에 각각 곱하면 \(Q = XW_Q\), \(K = XW_K\), \(V = XW_V\)를 한꺼번에 얻는다.

세 벡터가 같은 임베딩에서 나왔는데도 값이 서로 다른 것은 곱한 가중치가 다르기 때문이다. 한 단어가 찾는 것과 답이 되는 것과 건네는 내용은 서로 다를 수 있으므로 가중치를 따로 둔다.

점수와 비율

its는 어느 단어에서 정보를 가져와야 할까? 이것은 its의 Query와 다른 단어들의 Key가 얼마나 잘 맞는지로 정한다. 잘 맞는 정도는 10장에서 두 단어 벡터가 가까운 정도를 잴 때처럼 내적으로 잰다. 두 벡터의 방향이 비슷할수록 내적이 크므로, Query와 Key의 내적이 크면 그 단어가 찾는 것에 잘 맞는 단어라는 뜻이다.

모든 단어의 Query와 모든 단어의 Key를 한꺼번에 내적하려면 \(Q\)에 \(K\)를 전치한 \(K^T\)를 곱하면 된다. \(K^T\)는 다섯 단어의 Key를 세로로 세워 늘어놓은 2×5 행렬이므로, \(QK^T\)는 5×5 행렬이 된다. 아래 그림의 왼쪽이 이 곱이다.

{

\(QK^T\)의 \(i\)행 \(j\)열은 \(i\)번째 단어의 Query와 \(j\)번째 단어의 Key의 내적이다. 예를 들어 its 행 dog 열은 its의 Query \([2.0,\ 2.4]\)와 dog의 Key \([0.1,\ 2.7]\)의 내적 \(2.0 \times 0.1 + 2.4 \times 2.7 = 6.68\)이고, its 행에서 가장 크다. its의 Query에 가장 잘 맞는 단어가 dog라는 뜻이다. 이 내적을 점수라고 하자.

점수는 \(\sqrt{d_k}\)로 나누어 쓴다. 벡터의 차원이 커지면 곱해서 더하는 값이 많아져 점수가 지나치게 커지기 때문이다. 그런데 점수로는 어느 단어가 더 잘 맞는지 비교할 수 있지만, 각 단어에서 정보를 얼마만큼 가져올지 정하려면 비율이 필요하다. 그래서 3장에서 분류 문제의 출력층에 쓴 Softmax를 행마다 적용해 합이 1인 비율로 바꾸고, 그림의 오른쪽이 그 결과다. its 행이라면 점수 \([2.52,\ 6.68,\ 2.24,\ 5.2,\ 3.28]\)을 \(\sqrt{2}\)로 나눈 \([1.78,\ 4.72,\ 1.58,\ 3.68,\ 2.32]\)의 각 값에 \(e\)를 거듭제곱하고 그 합 172.78로 나누어 \([0.03,\ 0.65,\ 0.03,\ 0.23,\ 0.06]\)을 얻는다. its는 dog에게서 65%, 자기 자신에게서 23%를 가져오고, 나머지 단어에게서는 조금씩만 가져온다.

the 행은 차례로 \(0.4 \times 0.9 + 2.7 \times 0.3 = 1.17\), \(0.4 \times 0.1 + 2.7 \times 2.7 = 7.33\), \(0.4 \times 0.4 + 2.7 \times 0.6 = 1.78\), \(0.4 \times 0.8 + 2.7 \times 1.5 = 4.37\), \(0.4 \times 0.2 + 2.7 \times 1.2 = 3.32\)다. dog의 Key와의 내적이 가장 크므로 the는 dog에서 가장 많이 가져오고, 그림의 비율로도 the 행은 dog에 0.82를 준다.

비율대로 섞기: \(\times V\)

비율이 정해졌으니 이제 실제로 내용을 가져온다. 각 단어의 Value에 비율을 곱해 모두 더하면 되고, 다섯 단어를 한꺼번에 하려면 비율 행렬에 \(V\)를 곱한다. 비율 행렬은 5×5이고 \(V\)는 5×2이므로 곱은 5×2다.

its 줄의 첫째 값은 its의 비율 \([0.03,\ 0.65,\ 0.03,\ 0.23,\ 0.06]\)과 \(V\)의 첫째 열 \([0.5,\ 4.5,\ 1.0,\ 2.5,\ 2.0]\)을 곱해 더한 값이다.

\[\begin{aligned} &0.03 \times 0.5 + 0.65 \times 4.5 + 0.03 \times 1.0 \\ &\quad + 0.23 \times 2.5 + 0.06 \times 2.0 = 3.67 \end{aligned}\]

둘째 값도 같은 비율에 \(V\)의 둘째 열 \([3.2,\ -3.2,\ 0.8,\ 1.2,\ -0.8]\)을 곱해 더한 \(-1.73\)이다.

이 계산은 10장의 임베딩과 견주어 보면 뜻이 분명해진다. 원-핫 벡터에 \(W\)를 곱하면 1이 있는 자리의 행 하나만 꺼내졌다. 셀프 어텐션의 비율도 Value를 쌓은 행렬 \(V\)에 곱하는 벡터인데, 1이 한 자리에 몰려 있지 않고 여러 자리에 나뉘어 있다. 그래서 행 하나를 꺼내는 대신 여러 단어의 Value를 비율만큼 섞게 된다.

이렇게 얻은 \([3.67,\ -1.73]\)이 its가 문장에서 가져온 내용이다. 이 값의 대부분은 비율 0.65를 준 dog의 Value \([4.5,\ -3.2]\)에서 왔고, its 자신의 Value \([2.5,\ 1.2]\)가 0.23만큼 섞여 있다. 그러니 이 값은 its를 나타내는 벡터가 아니라, its의 벡터를 고쳐 쓰는 데 쓸 재료다.

첫째 값은 비율과 \(V\)의 첫째 열을 곱해 더한 값이다.

둘째 값은 \(V\)의 둘째 열로 같은 계산을 한다.

\[\begin{aligned} &0.01 \times 3.2 + 0.82 \times (-3.2) + 0.02 \times 0.8 \\ &\quad + 0.10 \times 1.2 + 0.05 \times (-0.8) = -2.496 \end{aligned}\]

식으로 쓰기

다섯 단어의 Query, Key, Value는 \(X\)에 가중치를 한 번씩 곱해 얻고, 모든 단어 쌍의 점수는 \(Q\)와 \(K^T\)의 곱 한 번으로, 다섯 단어가 가져온 내용은 비율 행렬과 \(V\)의 곱 한 번으로 얻는다. 이 계산을 식 하나로 쓰면 다음과 같다.

\[\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^T}{\sqrt{d_k}}\right) V\]

읽는 법: Query와 Key를 내적한 점수를 \(\sqrt{d_k}\)로 나누고, 행마다 Softmax로 비율을 만든 뒤, 그 비율로 Value를 섞는다. 이 결과가 다섯 단어가 가져온 내용이고, 여기에 \(X\)를 더하면 다섯 단어의 새 벡터가 한꺼번에 나온다.

\[X_{\text{새}} = X + \text{Attention}(Q, K, V)\]

위에서 단어를 바꾸어 보면, 다섯 단어가 저마다 다른 단어에게 주목하고 그 단어들의 화살표를 따라 서로 다른 방향으로 옮겨 가는 것을 볼 수 있다.

“The dog ate its”까지 쓴 상태에서 다음 단어를 고른다고 하자. 입력이 네 단어뿐이므로 셀프 어텐션도 네 단어 안에서 계산한다. its 줄의 점수를 \(\sqrt{2}\)로 나눈 값은 앞에서 구한 값에서 food를 뺀 \([1.78,\ 4.72,\ 1.58,\ 3.68]\)이고, Softmax를 거치면 비율은 the부터 차례로 \([0.04,\ 0.69,\ 0.03,\ 0.24]\), 가져온 내용은 \([3.76,\ -1.77]\)이 된다. 이것을 its의 임베딩에 더하면 새 벡터는 \([8.76,\ 6.23]\)이다. food가 빠진 몫만큼 나머지 비율이 조금씩 커졌을 뿐, its는 여전히 dog의 화살표를 따라 오른쪽 아래로 옮겨 간다.

이 새 벡터에 언임베딩 행렬 \(W_U\)를 곱해 어휘의 단어마다 점수를 낸다. 임베딩 행렬이 단어를 벡터로 바꾸었다면, 언임베딩 행렬은 반대로 벡터를 단어별 점수로 바꾼다. 어휘는 the, dog, ate, its, food, 마침표 여섯 개라고 하고, \(W_U\)를 다음과 같이 상정하자.

\[W_U = \begin{bmatrix} 0 & 0 & 0 & 0 & 0.3 & 0 \\ 0 & 0 & 0.1 & 0 & -0.1 & -0.1 \end{bmatrix}\]

\(W_U\)는 새 벡터의 값 2개를 단어 6개의 점수로 바꾸므로 2×6이고, 여섯 열이 차례로 the, dog, ate, its, food, 마침표의 점수를 만든다. 열 하나는 임베딩과 같은 2차원이므로 평면 위의 방향 하나로 그릴 수 있고, 단어의 점수는 새 벡터와 그 단어의 방향을 내적한 값이다. 그래서 새 벡터가 어떤 단어의 방향으로 멀리 나가 있을수록 그 단어의 점수가 크다. food의 열 \([0.3,\ -0.1]\)은 오른쪽을, ate의 열 \([0,\ 0.1]\)은 위쪽을, 마침표의 열 \([0,\ -0.1]\)은 아래쪽을 향하고, the, dog, its의 열은 0이다.

자기회귀 언어 모델 (Autoregressive Language Model)

앞의 단어들을 보고 다음 단어를 예측한 뒤, 예측한 단어를 입력 끝에 붙여 다시 다음 단어를 예측하는 일을 되풀이해 문장을 만드는 모델. GPT가 이 방식으로 글을 쓴다.

어떤 단어를 고를까: 온도

앞에서는 확률이 가장 큰 단어를 골랐다. 그런데 이렇게 하면 같은 입력에는 언제나 같은 문장이 나온다. 그래서 실제 언어 모델은 확률대로 뽑는 방법을 함께 쓴다. its 다음이라면 food를 58%, ate를 14%의 확률로 뽑는 식이다. 이때 확률을 얼마나 한쪽으로 몰지 정하는 값이 온도다.

온도 (Temperature)

Softmax를 적용하기 전에 점수를 나누는 값 \(T\). \(k\)번째 단어의 점수를 \(z_k\)라 하면 그 단어의 확률은 다음과 같다.

\[P(\text{단어}_k) = \frac{e^{z_k / T}}{\sum_{j} e^{z_j / T}}\]

\(T\)가 1보다 작으면 확률이 큰 단어로 더 몰리고, 1보다 크면 확률이 고르게 퍼진다.

앞의 점수로 \(T = 0.5\)일 때를 계산하면, 점수를 0.5로 나누어 두 배로 키운 뒤 Softmax를 적용하므로 food의 확률이 0.58에서 0.89로 올라간다. 온도를 낮추면 거의 항상 food를 뽑으므로 답이 안정적이지만 늘 비슷한 문장이 나오고, 온도를 높이면 ate나 dog 같은 다른 단어도 자주 뽑혀 문장이 다양해지는 대신 엉뚱한 문장이 나올 수도 있다. ChatGPT에 같은 질문을 해도 매번 조금씩 다른 답이 나오는 것은 이렇게 확률대로 뽑기 때문이다.

\(T = 2\)일 때 food의 확률을 구하라.

✍️ 직접 해보기 — 풀이

점수를 2로 나누면 \([0,\ 0,\ 0.31,\ 0,\ 1.005,\ -0.31]\)이고, 각각에 \(e\)를 거듭제곱하면 \([1.00,\ 1.00,\ 1.36,\ 1.00,\ 2.73,\ 0.73]\), 합은 7.82다. food의 확률은 \(2.73 \div 7.82 = \mathbf{0.35}\)로, \(T = 1\)의 0.58보다 작아져 확률이 고르게 퍼졌다.

학습할 때는 뒤 단어를 가린다

글을 쓸 때는 단어를 하나씩 만들어야 한다. 그렇다면 학습할 때도 한 단어씩 해야 할까? 학습 데이터에는 이미 완성된 문장이 있으므로 그럴 필요가 없다. “The dog ate its food.” 전체를 한 번에 넣으면 다섯 줄의 새 벡터가 한꺼번에 나오는데, 줄마다 자기 다음 단어를 맞히게 하면 된다.

줄 맞혀야 할 다음 단어
the dog
dog ate
ate its
its food
food .

문장 하나에서 문제가 다섯 개 나오고, 다섯 문제를 한 번의 계산으로 푼다. 줄마다 정답 단어의 확률로 3장의 교차 엔트로피를 구하고, 그 평균을 손실로 삼아 가중치를 고친다.

그런데 여기에는 문제가 있다. 앞에서 보았듯이 the 줄은 dog에서 0.82를 가져온다. the 줄이 맞혀야 할 정답이 dog인데 셀프 어텐션에서 이미 dog의 정보를 가져왔으므로, 답을 보면서 문제를 푸는 것과 같다. 이렇게 학습한 모델은 뒤 단어가 아직 없는 상태에서 글을 써야 할 때 쓸모가 없다. 그래서 학습할 때는 각 단어가 자기와 자기 앞의 단어만 보도록 뒤 단어를 가린다.

마스크드 어텐션 (Masked Attention)

         `${w} 줄의 비율 ${vec(AM[i0].slice(0, i0 + 1), f2)}은 "${prefix}"까지만 넣고 계산한 값과 같다.`]

앞에서 상정한 \(W_Q\), \(W_K\), \(W_V\), \(W_U\)도 바로 이 학습으로 정해진다. 처음에는 임의의 값에서 시작해, 다섯 줄의 교차 엔트로피 평균이 줄어드는 방향으로 경사하강법이 조금씩 고친다. its 다음의 food를 잘 맞히려면 its가 dog의 정보를 가져와야 하므로, 학습이 진행되면서 its의 Query와 dog의 Key가 잘 맞도록 가중치가 만들어진다.

연습

dog 줄의 점수 ÷ √2는 the부터 차례로 \([2.35,\ 0.83,\ 1.15,\ 2.35,\ 0.76]\)이다. 마스킹한 뒤 dog 줄의 비율을 구하라.

✍️ 직접 해보기 — 풀이

dog보다 뒤에 있는 ate, its, food의 칸에 \(-\infty\)가 들어가 비율이 0이 된다. 남은 the와 dog의 점수 \([2.35,\ 0.83]\)에 Softmax를 적용하면 \(e^{2.35} = 10.49\), \(e^{0.83} = 2.29\), 합은 12.78이므로 비율은 \(\mathbf{[0.82,\ 0.18]}\)이다. 마스킹하기 전에는 정답인 ate에서도 0.11을 가져왔지만, 이제는 ate를 보지 못한다.

트랜스포머의 구조

지금까지 본 계산을 모으면 GPT의 구조가 된다. 아래 그림을 아래에서 위로 읽어 보자.

입력: 임베딩과 위치 정보

맨 아래에서는 단어를 임베딩 벡터로 바꾼다. 그런데 셀프 어텐션은 단어의 내용만으로 비율을 정하므로, 단어가 문장의 몇 번째에 있는지는 알지 못한다. 그래서 문장 속 위치마다 그 위치를 나타내는 벡터를 하나씩 만들어 임베딩 벡터에 더한 뒤 입력으로 쓴다. 위치를 나타내는 벡터를 만드는 방법은 여러 가지가 있는데, 이 수업에서는 다루지 않는다.

멀티헤드 어텐션

입력은 먼저 마스크드 어텐션을 거친다. 앞에서는 가중치 묶음 \(W_Q\), \(W_K\), \(W_V\)를 하나만 썼는데, 단어 사이의 관계는 한 가지가 아니다. its에게는 누구의 것인지가 중요하지만 ate에게는 누가 먹었는지와 무엇을 먹었는지가 모두 중요하다. Harry라는 이름도 문맥에 따라 해리 포터가 되기도 하고 영국의 해리 왕자가 되기도 하듯이, 한 단어가 문장에서 읽어 내야 할 관계는 여러 가지다. 그래서 가중치 묶음을 여러 개 두고 같은 계산을 동시에 한다. 묶음 하나로 하는 셀프 어텐션을 헤드라고 한다.

멀티헤드 어텐션 (Multi-Head Attention)

서로 다른 가중치 묶음 \(W_Q\), \(W_K\), \(W_V\)로 셀프 어텐션을 여러 번 동시에 계산하고, 헤드마다 가져온 내용을 이어 붙여 하나로 합치는 것. 헤드마다 단어 사이의 다른 관계를 본다.

헤드마다 가져온 내용을 이어 붙이면 임베딩보다 길어지므로, 가중치 행렬 \(W_O\)를 한 번 더 곱해 임베딩과 같은 차원으로 맞춘 뒤 더한다. 헤드끼리는 서로의 결과를 기다리지 않으므로, 헤드가 늘어나도 동시에 계산할 수 있다.

잔차 연결과 정규화

4절에서 its가 가져온 내용을 its의 임베딩에 더한 것이 잔차 연결이었다. 어텐션의 결과에 어텐션에 들어가기 전의 입력을 그대로 더하는 것으로, 7장의 ResNet에서 본 것과 같다. 입력을 그대로 더하므로 its의 새 벡터는 자기 원래의 값을 지닌 채 dog에서 가져온 정보를 함께 담게 되고, 문맥을 반영하면서도 자기 뜻을 잃지 않는다. 더한 뒤에는 벡터마다 값의 크기를 일정한 범위로 맞추는 정규화를 한다.

층을 깊이 쌓으면 기울기가 아래층까지 잘 전달되지 않아 학습이 어려워지는데, 잔차 연결이 만든 우회 경로로는 기울기가 층을 건너뛰어 아래층까지 전달되고, 정규화는 층을 지날 때마다 값의 크기를 일정하게 맞춘다. 그래서 층을 수십 개 쌓아도 학습이 안정적으로 이루어진다.

피드포워드

다음은 피드포워드 층이다. 셀프 어텐션이 단어끼리 정보를 주고받는 곳이라면, 피드포워드 층은 단어마다 따로 2장의 다층 퍼셉트론을 거쳐 모은 정보를 가공하는 곳이다. 그 뒤에 한 번 더 잔차 연결과 정규화를 한다.

층을 쌓기

마스크드 멀티헤드 어텐션부터 두 번째 정규화까지가 한 층이다. 한 층의 출력은 입력과 모양이 같으므로 다음 층의 입력으로 그대로 넣을 수 있고, 이렇게 같은 구조의 층을 여러 번 쌓는다. GPT-3은 96층을 쌓았다. 층마다 셀프 어텐션과 피드포워드의 결과가 잔차 연결로 벡터에 더해지므로, 단어의 벡터는 층을 하나 지날 때마다 임베딩 공간 안에서 다시 옮겨 간다. 아래층에서 its가 dog의 정보를 담은 자리로 옮겨 갔다면, 위층에서는 그렇게 옮겨 간 벡터끼리 다시 정보를 주고받아 더 넓은 문맥을 담은 자리로 옮겨 간다.

출력

맨 위층까지 옮겨 간 벡터는 줄마다 언임베딩 행렬을 곱하고 Softmax를 거쳐 다음 단어의 확률이 된다. 앞에서 its 다음의 food를 고를 때 계산한 바로 그 단계로, 벡터가 마지막에 도착한 자리를 보고 다음 단어를 고른다. 학습할 때는 다섯 줄을 모두 써서 다섯 문제를 풀고, 글을 쓸 때는 마지막 줄만 써서 다음 단어를 고른다.

트랜스포머 (Transformer)

단어를 차례로 읽지 않고 문장 전체를 한 번에 받아, 셀프 어텐션으로 단어 사이의 연관도를 계산해 각 단어의 벡터를 문맥에 맞게 고쳐 쓰는 층을 여러 번 쌓은 신경망. GPT는 마스크드 어텐션을 쓰는 트랜스포머로 다음 단어를 예측한다.

순서는 어떻게 지키는가

문장을 한 번에 받으면 단어의 순서는 어떻게 될까? RNN은 읽는 차례가 곧 단어의 순서였지만, 트랜스포머는 순서를 따로 챙긴다. 학습할 때와 글을 쓸 때 모두 마스킹으로 각 단어가 자기와 앞의 단어만 보게 하므로 앞에서 뒤로 이어지는 문장의 방향이 계산에 그대로 남고, 입력에서는 단어가 몇 번째에 있는지를 나타내는 위치 정보를 임베딩에 더해 준다. 그리고 글을 쓸 때는 RNN과 마찬가지로 단어를 하나씩 만들어 입력 끝에 붙인다.

왜 효율적인가

첫째, 계산을 동시에 할 수 있다. RNN은 단어 수만큼 차례로 계산해야 했지만, 트랜스포머의 한 층은 문장의 길이와 상관없이 행렬 곱 몇 번으로 끝난다. 10장에서 본 것처럼 행렬 곱은 나누어 여러 GPU에 맡길 수 있으므로, 문장이 길어지고 모델이 커져도 GPU를 늘려 감당할 수 있다. 대신 위의 표처럼 함께 계산하는 점수의 칸 수는 단어 수를 제곱한 만큼 늘어난다.

둘째, 멀리 떨어진 단어의 정보도 바로 가져온다. 10장의 다음 문장을 다시 보자.

Those dogs ate their food, ……, they were very happy.

RNN에서는 dogs의 정보가 사이에 낀 단어 수만큼 은닉 상태를 거쳐야 they에 닿았고, 거칠 때마다 희미해졌다. 트랜스포머에서는 they의 Query와 dogs의 Key가 \(QK^T\)의 한 칸에서 바로 만나므로, 두 단어 사이에 단어가 몇 개 있든 거쳐야 할 단계가 없다.

셋째, 학습이 빠르다. 마스킹 덕분에 문장 하나를 한 번 넣으면 줄마다 다음 단어를 맞히는 문제를 모두 함께 풀 수 있다. RNN은 학습할 때도 시점마다 은닉 상태를 차례로 계산해야 했다. 트랜스포머를 인터넷 규모의 텍스트로 학습할 수 있게 된 것은 이 덕분이다.

넷째, 학습이 안정적이다. RNN의 기울기는 시점을 거슬러 갈 때마다 거듭 곱해져 사라지거나 폭발했다. 트랜스포머에는 시점을 따라 이어지는 경로가 없으므로 이런 곱셈이 생기지 않고, 층을 깊이 쌓을 때 생기는 기울기 문제는 잔차 연결과 정규화가 막는다.
