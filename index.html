수업의 세 층

층 무엇을 어떻게
손계산 원리 매주 문제집(도장) — 퍼셉트론, 콘볼루션, 어텐션을 손으로 계산
실습 응용 동작하는 코드를 읽고, 고치고, 실험하고, 해석 (백지 구현 없음)
프로젝트 종합 팀별로 직접 수집한 데이터로 이미지 분류 모델 구축

시험도 이 구조를 따른다 — 중간고사는 매주 문제집과 같은 유형의 손계산이다. 문제집을 성실히 풀었다면 시험 준비는 끝나 있다.

교재 사용법

이 사이트가 교재다. 각 장은 같은 리듬으로 진행된다:

  1. 학습 목표 — 이 장을 마치면 할 수 있어야 하는 것
  2. 개념과 수식 — 모든 수식은 숫자를 넣은 계산 예시와 함께 나온다
  3. 인터랙티브 위젯 — 슬라이더를 직접 움직여 개념을 실험한다. 눈으로만 읽지 말 것
  4. 핵심 요약 — 복습용 한 장 표

인터랙티브 위젯은 브라우저에서 바로 동작한다.

도장은 학번을 입력하면 본인 전용 문제가 만들어진다. “새 문제” 버튼으로 같은 유형을 무한히 연습할 수 있고, 답은 즉시 채점된다.

수강 환경

  • 이론·도장: 브라우저만 있으면 된다
  • 실습: Google Colab — 주차 카드의 Colab 배지를 누르면 노트북이 바로 열린다 (노트북 저장소)

1장에서는 딥러닝 이전의 기초 — 데이터, 모형, 파라미터, 학습이 무엇인지부터 시작한다.
