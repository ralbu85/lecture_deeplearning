실습 5-1 · 사진을 텐서로 만들고 콘볼루션을 코드로 계산하기

⏱ 45분 · 5주차 실습 1/2 — 사진을 (N, C, H, W) 텐서로 만들고 콘볼루션을 코드로 계산하기 → (5-2) 콘볼루션 층으로 옷 사진을 분류하기

🎯 이번 시간의 질문

지난 네 번의 실습에서 입력은 (데이터 수, 변수 수) 모양의 표였습니다. 오늘부터 입력은 사진입니다.

사진 한 장은 어떤 숫자 배열이고, 콘볼루션은 그 배열에 정확히 어떤 계산을 할까요?

사진을 열어 픽셀 값을 보고, PyTorch가 요구하는 모양으로 바꿔 배치로 꺼냅니다. 마지막에 이론 6장에서 손으로 계산한 콘볼루션을 F.conv2d로 계산해 같은 값이 나오는지 확인합니다.

데이터: FashionMNIST(28×28 흑백 옷 사진 7만 장), CIFAR-10(32×32 컬러 사진 6만 장). 코드에서 내려받습니다.

이번 시간에 반복할 패턴: np.array(img)로 배열 만들기 · ToTensor로 (C, H, W)와 0~1 · DataLoader에서 (N, C, H, W) 배치 꺼내기 · unsqueeze(0)으로 네 축 만들어 F.conv2d.

대응 이론: Ch05 컴퓨터 비전과 이미지 데이터 · Ch06 콘볼루션 연산

fmnist[0]은 사진 한 장과 정답 번호의 쌍입니다. 사진은 PIL 이미지이고, np.array로 숫자 배열이 됩니다.

# ✍️ 직접 입력
img, label = fmnist[0]

CIFAR-10은 32×32 컬러 사진입니다. 한 장을 배열로 만들면 축이 하나 더 있습니다.

# ✍️ 직접 입력
img_c, label_c = cifar[0]

print(cifar.classes[label_c])
print(arr.shape, arr.dtype)
print(arr[:, :, 0].shape)
frog
(32, 32, 3) uint8
(32, 32)

✅ 체크포인트 — frog, (32, 32, 3) uint8, (32, 32)면 맞습니다.

3. 신경망에 넣기 전 변환

PIL과 matplotlib은 (높이, 너비, 채널)로 다루지만, PyTorch는 채널을 앞에 두는 (채널, 높이, 너비)를 씁니다. transforms.ToTensor()는 PIL 이미지를 텐서로 바꾸면서 두 가지를 한꺼번에 합니다. 축을 (C, H, W)로 옮기고, 값을 255로 나누어 0~1 사이의 실수로 만듭니다. 픽셀의 최솟값 0과 최댓값 255는 어떤 사진이든 같으므로, 255로 나누는 것이 곧 min-max 스케일링입니다.

# ✍️ 직접 입력
to_tensor = transforms.ToTensor()
x = to_tensor(img_c)

print(tuple(x.shape), x.dtype)
print(x.min().item(), x.max().item())
print(arr[0, 0], x[:, 0, 0])
(3, 32, 32) torch.float32
0.0 1.0
[59 62 63] tensor([0.2314, 0.2431, 0.2471])

✅ 체크포인트 — (3, 32, 32) torch.float32, 0.0 1.0이면 맞습니다.

💬 결과 해설 — 마지막 줄이 왼쪽 위 픽셀 하나입니다. 배열에서는 [59 62 63]이던 R, G, B가 텐서에서는 0.2314, 0.2431, 0.2471입니다. 59/255 = 0.2314로, 같은 픽셀이 축 순서와 눈금만 바뀌어 들어 있습니다.

ToTensor()를 데이터셋에 transform으로 넘기면 사진을 꺼낼 때마다 자동으로 적용됩니다. 실습 4의 DataLoader를 그대로 써서 64장을 꺼냅니다.

# ✍️ 직접 입력
cifar_t = datasets.CIFAR10(root='../data', train=True, download=False, transform=transforms.ToTensor())
loader = DataLoader(cifar_t, batch_size=64, shuffle=True)

xb, yb = next(iter(loader))
print(tuple(xb.shape), tuple(yb.shape))
(64, 3, 32, 32) (64,)

✅ 체크포인트 — (64, 3, 32, 32) (64,)이면 맞습니다.

💬 결과 해설 — 앞으로 나오는 모든 이미지 텐서는 이 네 축 (N, C, H, W)를 갖습니다. N은 배치 크기, C는 채널, H와 W는 높이와 너비입니다. 실습 4의 (32, 9)에서 N은 그대로이고, 변수 축 하나가 (C, H, W) 세 축으로 바뀌었습니다.

4. 펼쳐서 넣으면 파라미터가 폭발한다

이론 5장의 방식대로 사진 한 장을 한 줄로 펼쳐 nn.Linear에 넣어 봅니다. flatten(start_dim=1)은 N축은 두고 나머지를 한 줄로 잇습니다. 은닉 노드는 5장과 같이 256개이고, 파라미터 수는 실습 2의 규칙 \(n_{\text{in}} \times n_{\text{out}} + n_{\text{out}}\)입니다.

# ✍️ 직접 입력
flat = xb.flatten(start_dim=1)
fc = nn.Linear(3 * 32 * 32, 256)

print(tuple(flat.shape))
print(fc.weight.shape, fc.bias.shape)
print(3 * 32 * 32 * 256 + 256)
(64, 3072)
torch.Size([256, 3072]) torch.Size([256])
786688

✅ 체크포인트 — 펼친 길이 3072, 가중치 (256, 3072), 파라미터 786,688개면 맞습니다.

💬 결과 해설 — 32×32짜리 작은 사진을 층 하나에 넣는 데 79만 개입니다. 5장의 224×224 사진이면 몇 개가 되는지는 과제 2에서 셉니다. 이것이 파라미터 폭발이고, 5절의 콘볼루션이 푸는 문제입니다.

5. 콘볼루션을 코드로 계산한다

이론 6장에서 손으로 계산한 2채널 예제를 그대로 가져옵니다. 채널 2개의 3×3 입력과 채널 2개의 2×2 커널이고, 6장과 같이 편향은 0입니다. 계산 원리는 6장에서 봤으므로 여기서는 PyTorch로 결과만 냅니다.

# ✍️ 직접 입력
x2 = torch.tensor([[[1, 2, 0], [0, 1, 3], [2, 1, 1]],
                   [[0, 1, 1], [2, 0, 1], [1, 2, 0]]], dtype=torch.float32)
k2 = torch.tensor([[[1, 0], [0, 1]],
                   [[0, 1], [1, 0]]], dtype=torch.float32)

print(x2.shape, k2.shape)
torch.Size([2, 3, 3]) torch.Size([2, 2, 2])

💬 결과 해설 — 입력은 (2, 3, 3), 커널은 (2, 2, 2)입니다. 첫 축이 채널이고, 커널의 채널 수는 입력의 채널 수와 같습니다.

PyTorch의 콘볼루션 F.conv2d는 배치 단위로 계산하므로 입력은 (N, C, H, W), 커널은 (커널 수, 입력 채널 수, KH, KW)여야 합니다. unsqueeze(0)은 맨 앞에 길이 1인 축을 하나 더합니다. 사진 한 장을 배치 하나로, 커널 한 개를 커널 묶음으로 만드는 것입니다.

# ✍️ 직접 입력
xt = x2.unsqueeze(0)
kt = k2.unsqueeze(0)

y = F.conv2d(xt, kt)
print(tuple(xt.shape), tuple(kt.shape), '->', tuple(y.shape))
print(y[0, 0])
(1, 2, 3, 3) (1, 2, 2, 2) -> (1, 1, 2, 2)
tensor([[5., 6.],
        [2., 5.]])

✅ 체크포인트 — (1, 2, 3, 3) (1, 2, 2, 2) -> (1, 1, 2, 2)이고 값이 [[5, 6], [2, 5]]면 맞습니다. 6장 보드의 마지막 스텝과 같은 값입니다.

💬 결과 해설 — 채널별 결과는 따로 쌓이지 않고 더해져서 특성 맵 한 장이 됩니다. - 커널의 두 번째 축은 입력 채널 수와 같아야 합니다. 콘볼루션에서 나는 모양 오류의 대부분이 이 축입니다. - 커널의 첫 축이 커널의 개수이고 그대로 출력 채널 수가 됩니다. 커널이 8개면 특성 맵도 8장입니다. 5-2에서 그렇게 씁니다.

📝 과제 1 · 텐서를 그림으로 보기

3절의 x는 (3, 32, 32)입니다. plt.imshow는 (높이, 너비, 채널)만 받으므로 축을 되돌려야 그릴 수 있습니다. permute로 축 순서를 바꿔 모양을 확인하고 그립니다.

# 📝
#> 힌트: x.permute(1, 2, 0)은 "원래 1번 축을 0번으로, 2번을 1번으로, 0번을 2번으로" 옮깁니다. 모양을 tuple(...shape)로 출력한 뒤 plt.imshow에 넣습니다.
back = x.permute(1, 2, 0)
print(tuple(back.shape))
plt.imshow(back)
plt.axis('off')
plt.show()
(32, 32, 3)

✏️ 나의 답: 되돌린 모양 (___, ___, ___)

예시 답: (32, 32, 3). 텐서를 그릴 때는 항상 permute(1, 2, 0)으로 되돌립니다. 실습 6·7에서 사진을 그릴 때 그대로 쓰입니다.

📝 과제 2 · 224×224 사진이면 파라미터는 몇 개인가

이론 5장의 224×224 컬러 사진을 같은 은닉 노드 256개에 연결할 때의 파라미터 수를 먼저 손으로 계산한 뒤 코드로 확인합니다.

# 📝
#> 힌트: 4절 셀에서 32를 224로 바꿉니다. nn.Linear(3 * 224 * 224, 256)의 weight.shape와 공식 3*224*224*256 + 256을 함께 출력합니다.
fc224 = nn.Linear(3 * 224 * 224, 256)
print(fc224.weight.shape)
print(3 * 224 * 224 * 256 + 256)
torch.Size([256, 150528])
38535424
입력 크기 펼친 길이 파라미터 수
32×32×3 3,072 786,688
224×224×3 ✏️ ✏️

예시 답: 펼친 길이 150,528, 파라미터 38,535,424개. 5장 “손으로 따라 계산하기”의 첫 연결 ①과 같은 수입니다.

📝 과제 3 · 세로 에지 커널

왼쪽 두 열이 10, 나머지가 0인 5×5 흑백 이미지에 이론 6장의 세로 에지 커널 [[1, 0, -1], [1, 0, -1], [1, 0, -1]]을 F.conv2d로 적용합니다. 출력 크기와 값이 큰 위치를 먼저 예상합니다.

# 📝
#> 힌트: 이미지는 torch.zeros(1, 5, 5)를 만든 뒤 img_e[0, :, :2] = 10으로 왼쪽 두 열을 채웁니다. 커널은 5절의 k2처럼 (1, 3, 3) 모양의 torch.tensor입니다. 둘 다 unsqueeze(0)으로 축을 하나 더해 F.conv2d에 넣고, 결과의 [0, 0]을 출력합니다.
img_e = torch.zeros(1, 5, 5)
img_e[0, :, :2] = 10
k_e = torch.tensor([[[1, 0, -1],
                     [1, 0, -1],
                     [1, 0, -1]]], dtype=torch.float32)
y_e = F.conv2d(img_e.unsqueeze(0), k_e.unsqueeze(0))
print(y_e[0, 0])
tensor([[30., 30.,  0.],
        [30., 30.,  0.],
        [30., 30.,  0.]])

✏️ 나의 답: 출력 크기 , 값이 큰 열

예시 답: 출력은 3×3이고 첫 두 열이 30, 셋째 열은 0입니다. 커널의 왼쪽 열(+1)이 밝은 칸 10에, 오른쪽 열(−1)이 어두운 칸 0에 걸치는 위치에서 값이 나옵니다. 커널 전체가 어두운 칸에 놓이는 셋째 열은 0입니다. 값이 큰 곳이 밝음에서 어두움으로 바뀌는 경계입니다.

📝 과제 4 · 생각해 보기

실습 4에서는 표준화의 평균과 표준편차를 훈련 세트에서 구했습니다. ToTensor가 255로 나눌 때는 왜 훈련 세트에서 값을 구하지 않아도 될까요? 한두 문장으로 적습니다.

✏️ 나의 답:

예시 답: 픽셀의 최솟값 0과 최댓값 255는 데이터에서 구한 통계가 아니라 이미지 형식이 정한 상수입니다. 어떤 사진에나 같으므로 훈련·검증·테스트에 같은 255를 쓰면 되고, 테스트 정보가 새어 들어갈 일도 없습니다. 평균·표준편차처럼 데이터에서 구하는 값은 실습 6에서 훈련 세트로 구합니다.
