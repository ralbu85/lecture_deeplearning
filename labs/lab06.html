실습 6 · CNN을 쌓아 내 사진을 분류하기

⏱ 75분 · 6주차 실습 — 콘볼루션·ReLU·풀링 블록을 쌓아 컬러 사진 열 종류를 분류하고, 직접 찍은 사진으로 시험하기

🎯 이번 시간의 질문

실습 5-2에서는 콘볼루션 층 하나로 흑백 옷 사진을 분류했습니다. 이번에는 콘볼루션 → ReLU → 풀링을 한 블록으로 묶어 여러 번 쌓고, 컬러 사진을 분류합니다.

블록을 쌓은 CNN은 내가 찍은 사진을 맞힐까요?

CIFAR-10 사진 4만 장으로 학습시킨 뒤, 휴대폰으로 찍은 사진을 올려 판별합니다.

이번 시간에 반복할 패턴: nn.MaxPool2d · 블록을 쌓으며 모양 찍기 · nn.Module로 특성 학습부와 분류부 조립 · Normalize로 채널별 표준화 · .to(device) · 사진 한 장을 학습 때와 같은 전처리로 바꿔 예측하기.

대응 이론: Ch07 CNN의 구조와 아키텍처

Colab 설정: 메뉴 런타임 → 런타임 유형 변경 → T4 GPU를 고른 뒤 시작합니다. 4절의 학습이 GPU에서 2~3분 걸립니다.

1. ReLU와 풀링을 층으로 쓴다

이론 7장의 행렬에 nn.ReLU를 적용합니다. 음수는 0이 되고 양수는 그대로 남습니다.

# ✍️ 직접 입력
relu = nn.ReLU()
z = torch.tensor([[-5., 3., 7.], [2., -3., 9.], [1., 1., -1.]])
print(relu(z))
tensor([[0., 3., 7.],
        [2., 0., 9.],
        [1., 1., 0.]])

✅ 체크포인트 — −5, −3, −1 세 칸만 0이 되면 맞습니다.

nn.MaxPool2d(2)는 사이즈 2, 스트라이드 2의 Max 풀링입니다. 이론 7장 풀링 보드의 4×4 특성 맵을 넣습니다. 층은 (N, C, H, W) 모양을 받으므로 unsqueeze(0)을 두 번 써서 (1, 1, 4, 4)로 만듭니다.

# ✍️ 직접 입력
pool = nn.MaxPool2d(2)
t = torch.tensor([[1., 2., 1., 0.],
                  [0., 1., 2., 3.],
                  [3., 0., 1., 2.],
                  [2., 4., 0., 1.]])
print(pool(t.unsqueeze(0).unsqueeze(0)))
tensor([[[[2., 3.],
          [4., 2.]]]])

✅ 체크포인트 — [[2., 3.], [4., 2.]]이면 맞습니다. 이론의 보드에서 네 창의 최댓값과 같습니다.

채널이 여섯 장인 14×14 특성 맵을 통과시키고, 풀링 층의 파라미터를 꺼내 봅니다.

# ✍️ 직접 입력
x = torch.zeros(1, 6, 14, 14)
print(pool(x).shape)
print(list(pool.parameters()))
torch.Size([1, 6, 7, 7])
[]

✅ 체크포인트 — torch.Size([1, 6, 7, 7])과 빈 목록 []이면 맞습니다.

💬 결과 해설 — 풀링은 채널마다 따로 적용되어 크기만 절반이 되고 채널 6은 그대로입니다. 최댓값을 고르는 규칙뿐이라 학습할 파라미터가 없습니다. nn.ReLU도 마찬가지입니다.

2. 블록을 쌓고 모양을 따라간다

3×3 콘볼루션 → ReLU → 2×2 Max 풀링을 한 블록으로 보고 세 번 쌓습니다. 커널 수는 32, 64, 128로 늘립니다. padding=1이면 3×3 콘볼루션은 크기를 유지하고(6장의 same), 풀링이 크기를 절반으로 줄입니다. 32×32 컬러 사진 한 장 모양의 입력을 넣고 실습 5-2처럼 층마다 모양을 찍습니다.

# ✍️ 직접 입력
features = nn.Sequential(
    nn.Conv2d(3, 32, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
    nn.Conv2d(32, 64, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
    nn.Conv2d(64, 128, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
)

h = torch.zeros(1, 3, 32, 32)
for layer in features:
    h = layer(h)
    print(layer.__class__.__name__, tuple(h.shape))
Conv2d (1, 32, 32, 32)
ReLU (1, 32, 32, 32)
MaxPool2d (1, 32, 16, 16)
Conv2d (1, 64, 16, 16)
ReLU (1, 64, 16, 16)
MaxPool2d (1, 64, 8, 8)
Conv2d (1, 128, 8, 8)
ReLU (1, 128, 8, 8)
MaxPool2d (1, 128, 4, 4)

✅ 체크포인트 — 마지막 줄이 MaxPool2d (1, 128, 4, 4)이면 맞습니다.

💬 결과 해설 — 크기는 풀링마다 32 → 16 → 8 → 4로 줄고, 채널은 3 → 32 → 64 → 128로 늘어납니다. 이론 7장의 LeNet-5처럼 특성 맵이 층을 지날수록 작아지고 두꺼워집니다.

뒤에 분류부를 붙입니다. 128×4×4를 펼쳐 은닉 256 노드에 넣고, 열 클래스의 점수를 냅니다.

# ✍️ 직접 입력
classifier = nn.Sequential(
    nn.Flatten(),
    nn.Linear(128 * 4 * 4, 256), nn.ReLU(),
    nn.Linear(256, 10),
)
print(classifier(h).shape)
torch.Size([1, 10])

✅ 체크포인트 — torch.Size([1, 10])이면 맞습니다.

두 부분을 모델 하나로 조립합니다. nn.Module을 물려받는 클래스를 만들고, __init__에는 층을, forward에는 계산 순서를 적습니다. super().__init__()은 nn.Module의 준비 작업을 먼저 실행하는 줄입니다. 실습 7부터 나오는 모델이 모두 이 형태입니다.

# ✍️ 직접 입력
class CNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 32, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(32, 64, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
            nn.Conv2d(64, 128, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2),
        )
        self.classifier = nn.Sequential(
            nn.Flatten(),
            nn.Linear(128 * 4 * 4, 256), nn.ReLU(),
            nn.Linear(256, 10),
        )

    def forward(self, x):
        h = self.features(x)
        return self.classifier(h)

torch.manual_seed(42)
model = CNN()
print(model(torch.zeros(2, 3, 32, 32)).shape)
torch.Size([2, 10])

✅ 체크포인트 — 사진 두 장을 넣어 torch.Size([2, 10])이 나오면 맞습니다.

💬 결과 해설 — self.features가 이론의 특성 학습부, self.classifier가 분류부입니다. model(x)를 부르면 forward가 실행됩니다.

4. GPU에서 학습시킨다

device는 계산할 장치입니다. GPU가 있으면 cuda, 없으면 cpu입니다. 모델을 .to(device)로 그 장치에 옮깁니다.

# ✍️ 직접 입력
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
print(device)
model = model.to(device)
cuda

✅ Colab에서 GPU 런타임이면 cuda가 나옵니다.

모델과 데이터는 같은 장치에 있어야 계산됩니다. 학습 함수는 실습 5-2의 것에 배치를 장치로 옮기는 줄 하나가 더해집니다. 빈칸을 채웁니다.

# ✍️ 빈칸(___)을 채운 뒤 실행하세요
#* def train_one_epoch(model, loader, criterion, optimizer):
#*     model.train()
#*     total = 0.0
#*     n = 0
#*     for xb, yb in loader:
#*         xb, yb = xb.to(___), yb.to(___)      # 배치를 모델과 같은 장치로
#*         optimizer.zero_grad()
#*         pred = model(xb)
#*         loss = criterion(pred, yb)
#*         loss.backward()
#*         optimizer.step()
#*         total += loss.item() * len(yb)
#*         n += len(yb)
#*     return total / n
def train_one_epoch(model, loader, criterion, optimizer):
    model.train()
    total = 0.0
    n = 0
    for xb, yb in loader:
        xb, yb = xb.to(device), yb.to(device)
        optimizer.zero_grad()
        pred = model(xb)
        loss = criterion(pred, yb)
        loss.backward()
        optimizer.step()
        total += loss.item() * len(yb)
        n += len(yb)
    return total / n

평가 함수도 같은 줄이 더해집니다.

# ✍️ 직접 입력
def evaluate(model, loader, criterion):
    model.eval()
    total = 0.0
    correct = 0
    n = 0
    with torch.no_grad():
        for xb, yb in loader:
            xb, yb = xb.to(device), yb.to(device)
            out = model(xb)
            total += criterion(out, yb).item() * len(yb)
            correct += (out.argmax(1) == yb).sum().item()
            n += len(yb)
    return total / n, correct / n

손실과 옵티마이저를 만들고, 학습 전의 검증 손실과 정확도를 봅니다.

# ✍️ 직접 입력
criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
print(evaluate(model, val_loader, criterion))
(2.302802442932129, 0.0843)

5. 내 사진을 판별한다

모델은 32×32로 표준화된 사진만 받습니다. 휴대폰 사진도 같은 모양으로 바꿉니다. Resize(32)는 짧은 변을 32로 줄이고, CenterCrop(32)는 가운데 32×32를 잘라 냅니다. 그 뒤는 학습 때와 같은 ToTensor와 Normalize입니다.

# ✍️ 직접 입력
photo_tf = transforms.Compose([
    transforms.Resize(32),
    transforms.CenterCrop(32),
    transforms.ToTensor(),
    transforms.Normalize(mean, std),
])

예시 사진으로 먼저 해 봅니다. scikit-image에 들어 있는 고양이 사진입니다.

예측합니다. 모델은 배치를 받으므로 unsqueeze(0)으로 (1, 3, 32, 32)를 만들고, 모델과 같은 장치로 옮깁니다. 점수 10개를 softmax로 확률로 바꿉니다.

# ✍️ 직접 입력

    out = model(x.unsqueeze(0).to(device))

💬 결과 해설 — 예측한 종류와 그 확률이 나옵니다. 같은 코드로 학습을 다시 하면 이 사진의 판별은 cat, dog, frog 사이에서 바뀝니다. 테스트 정확도는 매번 0.75 근처인데 사진 한 장의 판별은 흔들립니다.

사진 한 장을 받아 예측 이름과 확률을 돌려주는 함수로 조립합니다.

# ✍️ 직접 입력
def predict(photo):
    x = photo_tf(photo).unsqueeze(0).to(device)
    model.eval()
    with torch.no_grad():
        prob = torch.softmax(model(x), dim=1)[0]
    return tr_full.classes[prob.argmax().item()], prob.max().item()

print(predict(photo))

✅ 정리

배운 것 핵심
ReLU·풀링 층 nn.ReLU(), nn.MaxPool2d(2). 풀링은 크기 절반, 채널 유지. 둘 다 파라미터 없음
블록 쌓기 3×3 콘볼루션(padding=1) → ReLU → 풀링을 세 번. 32 → 16 → 8 → 4, 채널 3 → 32 → 64 → 128
모델 조립 class CNN(nn.Module). __init__에 특성 학습부와 분류부, forward에 계산 순서
채널별 표준화 transforms.Normalize(mean, std). 훈련 사진의 채널별 평균과 표준편차
GPU device, model.to(device), 배치마다 xb.to(device)
학습 결과 10 에폭, 테스트 정확도 약 0.75
내 사진 판별 Resize(32) → CenterCrop(32) → ToTensor → Normalize → unsqueeze(0) → softmax
