실습 4: 진짜 표 하나를 끝까지

이번 실습의 흐름

표 읽기 → 훈련·검증·테스트로 나누기 → 훈련 통계로 표준화·원-핫 → 텐서와 미니배치 → 학습 함수와 평가 함수 → 러닝커브 → 최적 지점 저장 → 테스트 세트 평가 순서로 진행한다.

실습 3에서는 학습에 쓴 데이터로 결과를 확인했다. 이번에는 자동차 표 하나로 새로운 데이터에 대한 성능을 재는 절차를 끝까지 따라간다. 각 셀을 실행하고 출력값을 확인한 뒤 다음 셀로 넘어간다. 중간의 직접 해보기는 먼저 작성한 뒤 노트북 끝의 해설과 비교한다.

2.2 train_test_split 두 번

3. 훈련 통계로 표준화하고 원-핫으로 바꾸기

3.1 평균과 표준편차는 훈련 세트에서만

숫자형 열은 단위가 제각각이다. 무게는 수천, 가속은 십 단위다. 실습 3처럼 학습이 되게 하려면 열마다 평균 0, 표준편차 1로 맞춘다.

이때 평균과 표준편차는 훈련 세트에서만 구한다. 전체 표로 구하면 테스트 데이터의 정보가 훈련에 새어 들어가, 성능이 실제보다 좋게 나온다.

num_cols = ['cylinders', 'displacement', 'horsepower', 'weight', 'acceleration', 'model_year']

mu = train_df[num_cols].mean()
sd = train_df[num_cols].std(ddof=0)
print(pd.DataFrame({'평균': mu, '표준편차': sd}).round(2))

pd.Categorical로 범주를 [1, 2, 3]으로 고정한다. 어느 세트에 우연히 유럽 차가 없어도 origin_2 열이 만들어져 세 세트의 열 개수가 같아진다.

3.3 함수 하나로 세 세트에 똑같이

표준화와 원-핫을 함수 하나에 넣고 세 세트에 같은 함수를 적용한다. 함수 안의 mu, sd는 훈련 세트의 값이다.

def prep(df):
    out = df.copy()
    out[num_cols] = (out[num_cols] - mu) / sd
    out['origin'] = pd.Categorical(out['origin'], categories=[1, 2, 3])
    return pd.get_dummies(out, columns=['origin'])

train_p, val_p, test_p = prep(train_df), prep(val_df), prep(test_df)
print(train_p.shape, val_p.shape, test_p.shape)
print(train_p[num_cols].mean().round(4))

세 세트의 열이 10개로 같다. 훈련 세트의 숫자형 열 평균은 정확히 0이다. 검증과 테스트 세트는 훈련의 평균을 뺐으므로 0이 아니어도 된다.

3.4 직접 해보기 ② — 순서를 바꾸면

전체 표 auto로 평균을 구한 뒤 훈련 세트를 표준화하면 훈련 세트의 평균이 0이 되지 않는다. 아래 셀을 완성해 확인한다.

# ① wrong_mu에 auto[num_cols]의 평균 저장
# ② (train_df[num_cols] - wrong_mu) / sd 의 열 평균을 소수 4자리로 출력

차이는 작아 보이지만, 테스트 데이터를 미리 들여다봤다는 사실은 변하지 않는다.

4. 텐서와 미니배치

4.1 표를 텐서로

독립변수 열을 X, mpg 열을 y로 나누어 텐서로 만든다. 실습 3과 같이 X는 (데이터 수, 변수 수), y는 (데이터 수, 1)이다.

import torch

feat = [c for c in train_p.columns if c != 'mpg']

def to_tensor(df):
    X = torch.tensor(df[feat].to_numpy(dtype='float32'))
    y = torch.tensor(df['mpg'].to_numpy(dtype='float32')).unsqueeze(1)
    return X, y

X_tr, y_tr = to_tensor(train_p)
X_va, y_va = to_tensor(val_p)
X_te, y_te = to_tensor(test_p)
print(X_tr.shape, y_tr.shape)
torch.Size([274, 9]) torch.Size([274, 1])

훈련 입력은 (274, 9)이다. 숫자형 6개에 원-핫 3개를 더해 변수가 9개다.

4.2 DataLoader로 나누어 꺼내기

실습 3에서는 매번 전체 X로 기울기를 구했다. 데이터가 크면 그럴 수 없으므로 배치로 나누어 꺼낸다. TensorDataset은 X와 y를 한 쌍으로 묶고, DataLoader는 그것을 batch_size씩 나눠 준다.

from torch.utils.data import TensorDataset, DataLoader

train_loader = DataLoader(TensorDataset(X_tr, y_tr), batch_size=32, shuffle=True)
val_loader = DataLoader(TensorDataset(X_va, y_va), batch_size=64)
test_loader = DataLoader(TensorDataset(X_te, y_te), batch_size=64)

print(len(train_loader))
9

274대를 32씩 나누면 9배치다. 마지막 배치는 18대다. 한 배치가 한 이터레이션이고, 9배치를 다 돌면 한 에폭이다.

shuffle=True는 에폭마다 순서를 섞어 배치 구성을 바꾼다. 훈련 로더에만 붙인다. 검증과 테스트는 섞을 이유가 없다.

4.3 한 배치 꺼내 보기

xb, yb = next(iter(train_loader))

5. 학습 함수와 평가 함수

5.1 한 에폭의 학습

실습 3의 다섯 줄을 배치마다 실행하고, 배치 손실의 평균을 돌려주는 함수를 만든다. model.train()은 모델을 학습 모드로 둔다.

def train_one_epoch(model, loader, criterion, optimizer):
    model.train()
    total = 0.0
    for xb, yb in loader:
        optimizer.zero_grad()
        pred = model(xb)
        loss = criterion(pred, yb)
        loss.backward()
        optimizer.step()
        total += loss.item() * len(yb)
    return total / len(loader.dataset)

loss.item() * len(yb)는 배치 손실을 배치 크기만큼 되돌린 합이다. 마지막 배치가 작아도 데이터 한 건이 같은 무게를 갖도록 전체 건수로 나눈다.

5.2 평가는 기울기 없이

검증과 테스트에서는 가중치를 바꾸지 않는다. model.eval()로 평가 모드로 두고, torch.no_grad() 안에서 손실만 계산한다.

def evaluate(model, loader, criterion):
    model.eval()
    total = 0.0
    with torch.no_grad():
        for xb, yb in loader:
            total += criterion(model(xb), yb).item() * len(yb)
    return total / len(loader.dataset)

train()과 eval()은 드롭아웃처럼 학습과 평가에서 다르게 동작하는 층을 전환한다. 지금 모델에는 그런 층이 없지만 항상 붙이는 습관을 들인다.

5.3 모델과 도구 준비

입력 9개를 받아 숫자 하나를 내는 모델이다. 은닉층 두 개를 둔다. 손실은 실습 3과 같은 MSELoss이고, 갱신 도구는 학습률을 스스로 조절하는 Adam을 쓴다.

import torch.nn as nn

torch.manual_seed(42)
model = nn.Sequential(
    nn.Linear(9, 32),
    nn.ReLU(),
    nn.Linear(32, 16),
    nn.ReLU(),
    nn.Linear(16, 1),
)
criterion = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

print(evaluate(model, val_loader, criterion))
613.0853881835938

학습 전 검증 손실이다. 연비의 제곱 단위이므로 수백이 나온다.

6. 학습하며 러닝커브 기록하기

6.1 에폭마다 훈련 손실과 검증 손실

에폭마다 훈련 함수와 평가 함수를 한 번씩 부르고 두 손실을 기록한다.

history = {'train': [], 'val': []}

for epoch in range(200):
    tr = train_one_epoch(model, train_loader, criterion, optimizer)
    va = evaluate(model, val_loader, criterion)
    history['train'].append(tr)
    history['val'].append(va)

print("첫 에폭  훈련:", round(history['train'][0], 2), " 검증:", round(history['val'][0], 2))
print("마지막   훈련:", round(history['train'][-1], 2), " 검증:", round(history['val'][-1], 2))
print("최소 검증 손실:", round(min(history['val']), 2), " 에폭:", history['val'].index(min(history['val'])))
첫 에폭  훈련: 600.54  검증: 523.16
마지막   훈련: 3.8  검증: 6.46
최소 검증 손실: 4.81  에폭: 93

마지막 에폭의 검증 손실이 최소 검증 손실보다 크다. 어느 에폭 이후로는 더 돌려도 새 데이터에 대한 성능이 좋아지지 않았다.

훈련 손실은 계속 내려가지만 검증 손실은 어느 지점부터 다시 오른다. 훈련 손실만 그리면 이 판단을 할 수 없다.

7. 최적 지점 저장과 조기 종료

7.1 가장 좋았던 가중치를 복사해 두기

학습을 다시 하되, 이번에는 검증 손실이 가장 낮았던 순간의 가중치를 복사해 둔다. model.state_dict()는 모델의 모든 가중치와 편향을 담은 사전이다. copy.deepcopy로 그 순간의 값을 따로 보관한다.

import copy

torch.manual_seed(42)
model = nn.Sequential(
    nn.Linear(9, 32), nn.ReLU(),
    nn.Linear(32, 16), nn.ReLU(),
    nn.Linear(16, 1),
)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

best_val, best_state, best_epoch = float('inf'), None, 0
for epoch in range(200):
    train_one_epoch(model, train_loader, criterion, optimizer)
    va = evaluate(model, val_loader, criterion)
    if va < best_val:
        best_val, best_state, best_epoch = va, copy.deepcopy(model.state_dict()), epoch

print("최적 에폭:", best_epoch, " 검증 손실:", round(best_val, 2))
print("마지막 검증 손실:", round(evaluate(model, val_loader, criterion), 2))
최적 에폭: 52  검증 손실: 5.05
마지막 검증 손실: 9.54

7.2 최적 지점으로 되돌리기

load_state_dict로 보관한 가중치를 모델에 다시 넣는다. 이것이 조기 종료다. 끝까지 돌리되 가장 좋았던 지점으로 되돌린다.

model.load_state_dict(best_state)
print("되돌린 뒤 검증 손실:", round(evaluate(model, val_loader, criterion), 2))
되돌린 뒤 검증 손실: 5.05

검증 손실이 최적 에폭의 값으로 돌아온다.

8. 테스트 세트로 최종 평가

8.1 한 번만 본다

테스트 세트는 지금까지 한 번도 쓰지 않았다. 여기서 딱 한 번 평가한다.

test_mse = evaluate(model, test_loader, criterion)
print("테스트 MSE :", round(test_mse, 2))
print("테스트 RMSE:", round(test_mse ** 0.5, 2))
테스트 MSE : 6.3
테스트 RMSE: 2.51

RMSE는 손실에 제곱근을 씌운 값이라 연비와 같은 단위다. 예측이 평균적으로 그만큼 빗나간다.

8.2 기준선과 비교

아무 모델 없이 훈련 세트의 평균 연비로만 예측하면 얼마나 틀리는지 구한다. 모델은 이 값보다 작아야 의미가 있다.

baseline = ((y_te - y_tr.mean()) ** 2).mean().item()
print("기준선 RMSE:", round(baseline ** 0.5, 2))
기준선 RMSE: 7.12

9. 직접 해보기 ④ — 모델 크기 바꾸기

은닉층이 8개뿐인 작은 모델과 128·64개인 큰 모델을 7.1절과 같은 방식으로 학습시켜 최적 에폭과 최적 검증 손실을 비교한다. 아래 준비 셀은 그대로 실행한다.

def train_with_best(model, epochs=200):
    optimizer = torch.optim.Adam(model.parameters(), lr=0.01)
    best_val, best_epoch = float('inf'), 0
    for epoch in range(epochs):
        train_one_epoch(model, train_loader, criterion, optimizer)
        va = evaluate(model, val_loader, criterion)
        if va < best_val:
            best_val, best_epoch = va, epoch
    return best_epoch, best_val

다음 셀의 주석을 코드로 바꾼다.

마무리

표 하나를 나누고, 훈련 통계로 변환하고, 배치로 학습하고, 검증 손실로 멈출 지점을 고르고, 테스트 세트로 한 번 보고했다. 모든 통계량은 훈련 세트에서만 구하고 검증·테스트에는 그 값을 그대로 적용한다. 학습 다섯 줄은 실습 3과 같고, 그 앞뒤에 DataLoader와 train()/eval(), state_dict가 붙었다.

④ 모델 크기 바꾸기 
torch.manual_seed(42)
small = nn.Sequential(nn.Linear(9, 8), nn.ReLU(), nn.Linear(8, 1))
big = nn.Sequential(nn.Linear(9, 128), nn.ReLU(),
                    nn.Linear(128, 64), nn.ReLU(), nn.Linear(64, 1))

for name, m in [('small', small), ('big', big)]:
    n_params = sum(p.numel() for p in m.parameters())
    best_epoch, best_val = train_with_best(m)
    print(name, n_params, best_epoch, round(best_val, 2))

작은 모델은 파라미터 89개, 큰 모델은 9,601개다. 큰 모델은 훈련 데이터를 빨리 외우므로 최적 에폭이 일찍 오고, 그 뒤 검증 손실이 오른다. 작은 모델은 최적 에폭이 늦고 최적 검증 손실도 대체로 더 높다. 실행 결과는 초기 가중치와 배치 순서에 따라 조금씩 다르다.
