실습 4: 진짜 표 하나를 끝까지

이번 실습의 흐름

표 읽기 → 세 세트로 나누기 → 열 하나를 표준화 → 열 하나를 원-핫 → 전처리 함수로 조립 → 텐서와 배치 → 배치 하나로 학습 다섯 줄 → 한 에폭 → 학습 함수로 조립 → 검증 손실 한 번 → 평가 함수로 조립 → 에폭 반복과 러닝커브 → 가중치 복사와 복원 → 테스트 평가 순서로 진행한다.

실습 3에서는 학습에 쓴 데이터로 결과를 확인했다. 이번에는 자동차 표 하나로 새로운 데이터에 대한 성능을 재는 절차를 끝까지 따라간다. 각 절에서 핵심 코드를 한 줄씩 실행해 값을 확인하고, 그다음에 그 줄들을 함수로 조립한다. 중간의 직접 해보기는 먼저 작성한 뒤 노트북 끝의 해설과 비교한다.

대응 이론: Ch04 학습의 실전. Colab 기본 CPU 런타임을 사용한다. 데이터는 코드에서 내려받는다.

3. 표준화 — 열 하나부터

3.1 훈련 세트에서 평균과 표준편차

weight 열은 수천, acceleration 열은 십 단위다. 열마다 평균 0, 표준편차 1로 맞춘다. 평균과 표준편차는 훈련 세트에서 구한다. 먼저 weight 열 하나로 해 본다.

w_mean = train_df['weight'].mean()
w_std = train_df['weight'].std(ddof=0)
print(w_mean, w_std)
2986.485401459854 837.4454518494796

훈련 세트 274대의 무게 평균은 약 2986, 표준편차는 약 837이다. ddof=0은 표준편차의 분모를 \(n\)으로 두는 옵션이다.

3.2 훈련 세트의 열을 표준화

각 값에서 평균을 빼고 표준편차로 나눈다.

w_train = (train_df['weight'] - w_mean) / w_std
print(w_train.mean(), w_train.std(ddof=0))
-6.969283220274705e-17 0.9999999999999999

평균 0, 표준편차 1이 된다. 자기 평균을 빼고 자기 표준편차로 나눴으니 당연하다.

3.3 검증 세트의 열에 같은 값을 적용

검증 세트는 검증 세트의 평균이 아니라 훈련 세트의 평균과 표준편차로 변환한다.

w_val = (val_df['weight'] - w_mean) / w_std
print(w_val.mean(), w_val.std(ddof=0))
-0.08372189489963786 0.9789892659943903

평균 약 -0.08, 표준편차 약 0.98이다. 0과 1이 아니다. 훈련 세트의 값을 썼기 때문이다. 검증과 테스트 세트는 항상 이렇게 변환한다. 모델이 배운 것은 훈련 세트의 눈금이므로, 새 데이터도 그 눈금으로 재야 한다.

3.4 여섯 열을 한꺼번에

같은 계산을 숫자형 여섯 열에 한 번에 한다. mu와 sd는 열마다 값이 하나씩 있는 벡터다.

mu = train_df[num_cols].mean()
sd = train_df[num_cols].std(ddof=0)

평균을 훈련 세트가 아니라 전체 표 auto에서 구한 뒤 훈련 세트를 표준화하면, 훈련 세트의 평균이 0이 되지 않는다. 아래 셀을 완성해 확인한다.

# ① wrong_mu에 auto[num_cols]의 평균 저장
# ② (train_df[num_cols] - wrong_mu) / sd 의 열 평균을 소수 4자리로 출력

4.2 범주가 빠지면 열이 빠진다

작은 예로 확인한다. 값이 1과 3뿐인 열을 원-핫으로 바꾸면 열이 두 개만 나온다.

small = pd.Series([1, 3, 1], name='origin')

origin_2가 없다. 검증이나 테스트 세트에 우연히 유럽 차가 없으면 이런 일이 생기고, 열 개수가 달라 모델에 넣을 수 없다.

4.3 pd.Categorical로 범주를 고정

범주를 [1, 2, 3]으로 미리 알려 주면 값이 없어도 열이 만들어진다.

small_fixed = pd.Categorical(small, categories=[1, 2, 3])

origin_2 열이 0으로 채워져 나온다. 세 세트 모두 이 방식으로 바꾼다.

5. 전처리 함수로 조립

3.4절의 표준화와 4.3절의 원-핫을 한 함수에 넣는다. 함수 안의 mu, sd는 훈련 세트에서 구한 값이다.

def prep(df):
    out = df.copy()
    out[num_cols] = (out[num_cols] - mu) / sd
    out['origin'] = pd.Categorical(out['origin'], categories=[1, 2, 3])
    return pd.get_dummies(out, columns=['origin'])

train_p = prep(train_df)

6. 텐서와 배치

6.1 훈련 세트를 텐서로

독립변수 아홉 열을 X, mpg 열을 y로 나눈다. 실습 3과 같이 X는 (데이터 수, 변수 수), y는 (데이터 수, 1)이다.

import torch

feat = [c for c in train_p.columns if c != 'mpg']

X_tr = torch.tensor(train_p[feat].to_numpy(dtype='float32'))
y_tr = torch.tensor(train_p['mpg'].to_numpy(dtype='float32')).unsqueeze(1)
print(X_tr.shape, y_tr.shape)
torch.Size([274, 9]) torch.Size([274, 1])

(274, 9)와 (274, 1)이다. 검증과 테스트도 같은 두 줄이므로 함수로 만든다.

def to_tensor(df):
    X = torch.tensor(df[feat].to_numpy(dtype='float32'))
    y = torch.tensor(df['mpg'].to_numpy(dtype='float32')).unsqueeze(1)
    return X, y

X_va, y_va = to_tensor(val_p)
X_te, y_te = to_tensor(test_p)
print(X_va.shape, X_te.shape)
torch.Size([59, 9]) torch.Size([59, 9])

6.2 DataLoader

실습 3에서는 매번 274건 전체로 기울기를 구했다. 이번에는 32건씩 나누어 구한다. TensorDataset은 X와 y를 한 쌍으로 묶고, DataLoader는 그것을 batch_size씩 나눠 준다.

from torch.utils.data import TensorDataset, DataLoader

torch.manual_seed(42)
train_loader = DataLoader(TensorDataset(X_tr, y_tr), batch_size=32, shuffle=True)
print(len(train_loader))
9

9다. 274건을 32씩 나누면 8배치에 18건이 남아 9배치다. 한 배치가 한 이터레이션이고, 9배치를 다 돌면 한 에폭이다. shuffle=True는 에폭마다 순서를 섞는다. 그 앞의 torch.manual_seed(42)는 섞는 순서를 고정해 실행할 때마다 같은 결과가 나오게 한다.

7. 배치 하나로 학습 다섯 줄

7.1 모델 준비

입력 9개를 받아 숫자 하나를 낸다. 은닉층은 32개와 16개다. 손실은 실습 3과 같은 MSELoss이고, 갱신 도구는 Adam을 쓴다.

import torch.nn as nn

torch.manual_seed(42)
model = nn.Sequential(
    nn.Linear(9, 32),
    nn.ReLU(),
    nn.Linear(32, 16),
    nn.ReLU(),
    nn.Linear(16, 1),
)
criterion = nn.MSELoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)
print(model)
Sequential(
  (0): Linear(in_features=9, out_features=32, bias=True)
  (1): ReLU()
  (2): Linear(in_features=32, out_features=16, bias=True)
  (3): ReLU()
  (4): Linear(in_features=16, out_features=1, bias=True)
)

7.2 배치 하나에 다섯 줄

6.3절에서 꺼낸 배치 xb, yb에 실습 3의 다섯 줄을 그대로 적용한다.

optimizer.zero_grad()
pred = model(xb)
loss = criterion(pred, yb)
loss.backward()
optimizer.step()
print(loss.item())
555.7430419921875

약 556이다. 이 배치 32건의 손실이고, 연비의 제곱 단위이므로 수백이 나온다. 가중치는 이 배치의 기울기로 한 번 갱신되었다.

7.3 다음 배치

로더에서 다음 배치를 꺼내 같은 다섯 줄을 실행한다.

xb, yb = next(iter(train_loader))
optimizer.zero_grad()
pred = model(xb)
loss = criterion(pred, yb)
loss.backward()
optimizer.step()
print(loss.item())
524.6473388671875

약 525다. 다른 32건이므로 손실값이 다르다. 배치마다 이렇게 한 번씩 갱신한다.

7.4 모든 배치를 돌면 한 에폭

for로 로더의 배치를 차례로 꺼내 다섯 줄을 실행한다. 배치 손실은 32건의 평균이므로 배치 크기를 곱해 합으로 되돌려 모으고, 마지막에 전체 건수로 나누면 에폭의 평균 손실이 된다.

total = 0.0
for xb, yb in train_loader:
    optimizer.zero_grad()
    pred = model(xb)
    loss = criterion(pred, yb)
    loss.backward()
    optimizer.step()
    total += loss.item() * len(yb)

print(total / len(train_loader.dataset))
580.0024890760436

약 580이다. 한 에폭의 평균 훈련 손실이고, len(train_loader.dataset)은 274다.

7.5 학습 함수로 조립

7.4절의 코드를 함수로 만든다. 앞에 model.train()을 붙인다. 모델을 학습 모드로 두는 줄이다.

def train_one_epoch(model, loader, criterion, optimizer):
    model.train()
    total = 0.0
    for xb, yb in loader:
        optimizer.zero_grad()
        pred = model(xb)
        loss = criterion(pred, yb)
        loss.backward()
        optimizer.step()
        total += loss.item() * len(yb)
    return total / len(loader.dataset)

print(train_one_epoch(model, train_loader, criterion, optimizer))
369.96989897567863

약 370이다. 한 에폭을 더 돌아 7.4절보다 손실이 줄었다.

8. 검증 손실 재기

8.1 검증 세트 전체로 한 번

검증 세트로는 가중치를 바꾸지 않고 손실만 잰다. 실습 3의 7.3절처럼 torch.no_grad() 안에서 계산한다. model.eval()은 모델을 평가 모드로 바꾼다. 드롭아웃처럼 학습과 평가에서 다르게 동작하는 층을 전환하는 줄이다.

model.eval()
with torch.no_grad():
    val_loss = criterion(model(X_va), y_va)
print(val_loss.item())
171.53688049316406

약 171.5이다. 검증 59건의 평균 손실이다.

8.2 배치로 나눠 재도 같다

로더로 배치마다 손실을 구해 합치면 같은 값이 나온다. 데이터가 커서 한 번에 못 넣을 때는 이렇게 한다.

total = 0.0
with torch.no_grad():
    for xb, yb in val_loader:
        total += criterion(model(xb), yb).item() * len(yb)
print(total / len(val_loader.dataset))
171.53688049316406

8.1절과 같은 값이다.

8.3 평가 함수로 조립

def evaluate(model, loader, criterion):
    model.eval()
    total = 0.0
    with torch.no_grad():
        for xb, yb in loader:
            total += criterion(model(xb), yb).item() * len(yb)
    return total / len(loader.dataset)

print(evaluate(model, val_loader, criterion))
171.53688049316406

같은 값이다. 이제 학습 함수와 평가 함수가 갖춰졌다.

10. 가중치 복사와 복원

10.1 state_dict

모델의 가중치와 편향은 model.state_dict()에 들어 있다. 이름과 텐서의 사전이다.

state = model.state_dict()
print(list(state.keys()))
print(state['4.bias'])
['0.weight', '0.bias', '2.weight', '2.bias', '4.weight', '4.bias']
tensor([0.1830])

층 번호와 weight/bias로 이름이 붙어 있다. 4.bias는 마지막 Linear 층의 편향 하나로, 약 0.1830이다.

10.2 복사해 두면 학습해도 그대로

copy.deepcopy로 지금 값을 따로 복사한다. 그 뒤 한 에폭 더 학습하면 모델의 값은 바뀌지만 복사본은 그대로다.

import copy

saved = copy.deepcopy(model.state_dict())
train_one_epoch(model, train_loader, criterion, optimizer)

print("복사본:", saved['4.bias'])
print("모델  :", model.state_dict()['4.bias'])
복사본: tensor([0.1830])
모델  : tensor([0.1823])

복사본은 0.1830 그대로이고 모델은 0.1823으로 바뀌었다. deepcopy가 없으면 복사본도 모델을 따라 바뀐다.

10.3 되돌리기

load_state_dict로 복사본을 모델에 다시 넣는다.

model.load_state_dict(saved)
print(model.state_dict()['4.bias'])
tensor([0.1830])

복사본의 값으로 돌아왔다.

10.4 조립 — 최적 지점을 기억하며 학습

새 모델로 다시 학습하되, 검증 손실이 지금까지 가장 낮을 때마다 가중치를 복사해 둔다. 9.1절의 반복문에 if 세 줄이 더해진 것이다.

torch.manual_seed(42)
model = nn.Sequential(
    nn.Linear(9, 32), nn.ReLU(),
    nn.Linear(32, 16), nn.ReLU(),
    nn.Linear(16, 1),
)
optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

best_val, best_state, best_epoch = float('inf'), None, 0
for epoch in range(200):
    train_one_epoch(model, train_loader, criterion, optimizer)
    va = evaluate(model, val_loader, criterion)
    if va < best_val:
        best_val = va
        best_state = copy.deepcopy(model.state_dict())
        best_epoch = epoch

print("최적 에폭:", best_epoch, " 그때 검증 손실:", round(best_val, 1))
print("마지막 검증 손실:", round(evaluate(model, val_loader, criterion), 1))
최적 에폭: 52  그때 검증 손실: 5.0
마지막 검증 손실: 9.5

10.5 최적 지점으로 복원

model.load_state_dict(best_state)

5.0

최적 에폭의 값 5.0로 돌아왔다. 되돌리기 전의 마지막 검증 손실은 9.5였다. 끝까지 돌리고 가장 좋았던 지점으로 되돌리는 것, 이것이 조기 종료다.

11. 테스트 세트로 최종 평가

11.1 한 번만 본다

테스트 세트는 지금까지 쓰지 않았다. 복원한 모델로 여기서 한 번 평가한다.

test_mse = evaluate(model, test_loader, criterion)
print(round(test_mse, 1), round(test_mse ** 0.5, 2))
6.3 2.51

MSE 약 6.3, RMSE 약 2.5다. RMSE는 MSE에 제곱근을 씌워 연비와 같은 단위로 만든 것이다. 예측이 평균적으로 그만큼 빗나간다.

11.2 기준선

모델 없이 훈련 세트의 평균 연비로만 예측하면 얼마나 틀리는지 구한다.

baseline_mse = ((y_te - y_tr.mean()) ** 2).mean().item()

7.12

약 7.1이다. 모델의 RMSE 2.5는 기준선의 3분의 1 수준이다.

표 하나를 나누고, 훈련 세트의 평균·표준편차로 변환하고, 배치로 학습하고, 검증 손실로 멈출 지점을 고르고, 테스트 세트로 한 번 평가했다. 학습 다섯 줄은 실습 3과 같다. 그 다섯 줄을 배치마다 돌리면 train_one_epoch, no_grad 안에서 손실만 모으면 evaluate, 검증 손실이 낮을 때 state_dict를 복사해 두면 조기 종료다.
