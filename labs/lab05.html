실습 5: 이미지를 텐서로, 콘볼루션을 코드로

이번 실습의 흐름

이미지 한 장을 숫자 배열로 → 채널과 축 순서 → 신경망에 넣기 전 변환 → 배치 텐서 (N, C, H, W) → 콘볼루션을 직접 계산 → F.conv2d와 대조 → 출력 크기 공식 → 콘볼루션 층의 파라미터 수 → 작은 CNN으로 옷 사진 분류 순서로 진행한다.

지난 네 번의 실습에서 입력은 (데이터 수, 변수 수) 모양의 표였다. 오늘부터 입력은 사진이다. 사진이 어떤 숫자 배열인지 확인하고, 이론에서 손으로 계산한 콘볼루션을 코드로 재현한 뒤, 마지막에 파라미터 235개짜리 CNN을 학습시킨다. 각 셀을 실행하고 출력값을 확인한 뒤 다음 셀로 넘어간다. 중간의 직접 해보기는 먼저 작성한 뒤 노트북 끝의 해설과 비교한다.

대응 이론: Ch05 컴퓨터 비전과 이미지 데이터, Ch06 콘볼루션 연산. Colab 기본 CPU 런타임을 사용한다. 데이터는 코드에서 내려받는다.

1.1 흑백 옷 사진 데이터

2. 컬러 이미지와 채널

2.1 (높이, 너비, 채널)

CIFAR-10은 32×32 컬러 사진이다. 한 장을 배열로 만들면 축이 하나 더 있다.

cifar = datasets.CIFAR10(root='../data', train=True, download=True)
img_c, label_c = cifar[0]
arr = np.array(img_c)

print(cifar.classes[label_c])
print(arr.shape, arr.dtype)
Files already downloaded and verified
frog
(32, 32, 3) uint8

(32, 32, 3)이다. 마지막 축 3이 R, G, B 채널이다. 컬러 사진 한 장은 같은 크기의 흑백 행렬 세 장을 겹친 것이다.

2.2 채널 하나만 꺼내기

마지막 축에서 0번을 고르면 빨강 채널 한 장이 나온다.

red = arr[:, :, 0]
print(red.shape)
print(arr.mean(axis=(0, 1)).round(1))
(32, 32)
[141.2 105.1  64. ]

axis=(0, 1)은 높이와 너비 축을 없애고 채널마다 평균 하나를 남긴다. 실습 1의 축 규칙이 그대로 적용된다.

2.3 축 순서 바꾸기: (H, W, C)에서 (C, H, W)로

PIL과 matplotlib은 (높이, 너비, 채널)로 다루지만, PyTorch는 채널을 앞에 두는 (채널, 높이, 너비)를 쓴다. permute로 축의 순서를 바꾼다.

t_hwc = torch.tensor(arr)
t_chw = t_hwc.permute(2, 0, 1)

print(tuple(t_hwc.shape), '->', tuple(t_chw.shape))
(32, 32, 3) -> (3, 32, 32)

permute(2, 0, 1)은 “원래 2번 축을 0번으로, 0번을 1번으로, 1번을 2번으로” 옮긴다. 값은 그대로이고 축의 자리만 바뀐다.

3. 신경망에 넣기 전 변환

3.1 ToTensor가 하는 두 가지

transforms.ToTensor()는 PIL 이미지를 텐서로 바꾸면서 두 가지를 한꺼번에 한다. 축을 (C, H, W)로 옮기고, 값을 255로 나누어 0~1 사이의 실수로 만든다.

to_tensor = transforms.ToTensor()
x = to_tensor(img_c)

print(tuple(x.shape), x.dtype)
print(round(x.min().item(), 4), round(x.max().item(), 4))
(3, 32, 32) torch.float32
0.0 1.0

직접 계산해 같은지 대조한다.

manual = arr.transpose(2, 0, 1) / 255.0
print(np.allclose(x.numpy(), manual))
True

3.2 Normalize: 채널마다 평균을 빼고 표준편차로 나누기

실습 4에서 표의 열마다 표준화했듯이, 이미지는 채널마다 표준화한다. Normalize(mean, std)는 채널별로 \((x-\mu)/\sigma\)를 계산한다.

normalize = transforms.Normalize(mean=(0.5, 0.5, 0.5), std=(0.5, 0.5, 0.5))
xn = normalize(x)

print(round(xn.min().item(), 4), round(xn.max().item(), 4))
print(round((x[0, 0, 0].item() - 0.5) / 0.5, 4), round(xn[0, 0, 0].item(), 4))
-1.0 1.0
-0.5373 -0.5373

0~1이던 값이 -1~1로 옮겨졌다. 첫 픽셀을 손으로 계산한 값과 Normalize의 값이 같다.

3.3 Compose로 묶기

변환 여러 개를 순서대로 적용하는 파이프라인이다. Normalize는 텐서를 받으므로 ToTensor 뒤에 와야 한다.

pipeline = transforms.Compose([
    transforms.ToTensor(),
    transforms.Normalize((0.5, 0.5, 0.5), (0.5, 0.5, 0.5)),
])

out = pipeline(img_c)
print(tuple(out.shape))
(3, 32, 32)

이 파이프라인을 데이터셋에 transform으로 넘기면 사진을 꺼낼 때마다 자동으로 적용된다.

4. 배치 텐서 (N, C, H, W)

4.1 DataLoader로 여러 장을 한 번에

실습 4의 DataLoader를 그대로 쓴다. 파이프라인을 붙인 데이터셋에서 64장을 꺼낸다.

from torch.utils.data import DataLoader

cifar_t = datasets.CIFAR10(root='../data', train=True, download=False, transform=pipeline)
loader = DataLoader(cifar_t, batch_size=64, shuffle=True)

xb, yb = next(iter(loader))
print(tuple(xb.shape), tuple(yb.shape))
(64, 3, 32, 32) (64,)

입력 배치는 (64, 3, 32, 32)다. 앞으로 나오는 모든 이미지 텐서는 이 네 축 (N, C, H, W)를 갖는다. N은 배치 크기, C는 채널, H와 W는 높이와 너비다.

4.2 펼쳐서 완전연결층에 넣으면

이론 5장의 방식대로 사진 한 장을 한 줄로 펼쳐 nn.Linear에 넣어 본다. flatten(start_dim=1)은 N축은 두고 나머지를 한 줄로 잇는다.

import torch.nn as nn

flat = xb.flatten(start_dim=1)
fc = nn.Linear(3 * 32 * 32, 128)

print(tuple(flat.shape))
print(sum(p.numel() for p in fc.parameters()))
(64, 3072)
393344

펼친 길이는 3,072이고, 은닉 노드 128개에 연결하면 파라미터가 393,344개다. \(3072 \times 128 + 128\)과 같다.

5. 콘볼루션을 직접 계산하기

5.1 곱해서 더하며 한 칸씩 옮기기

커널을 이미지 위에 놓고, 겹친 칸끼리 곱해서 모두 더한 값을 하나 적는다. 커널을 한 칸 옮겨 반복한다. 이중 for문으로 그대로 옮긴다.

def conv2d_naive(x, k, b=0.0):
    """x: (C, H, W), k: (C, KH, KW) -> (OH, OW). stride 1, padding 0"""
    C, H, W = x.shape
    _, KH, KW = k.shape
    out = np.zeros((H - KH + 1, W - KW + 1))
    for i in range(H - KH + 1):
        for j in range(W - KW + 1):
            patch = x[:, i:i + KH, j:j + KW]
            out[i, j] = (patch * k).sum() + b
    return out

patch는 커널과 같은 크기로 잘라 낸 입력 조각이다. 채널이 여러 개면 모든 채널의 곱을 한꺼번에 더한다.

5.2 이론 6장의 2채널 예제

이론에서 손으로 계산한 입력 채널 2개, 3×3 이미지에 2×2 커널을 적용한 예제다.

x2 = np.array([[[1, 2, 0], [0, 1, 3], [2, 1, 1]],
               [[0, 1, 1], [2, 0, 1], [1, 2, 0]]], dtype=np.float32)
k2 = np.array([[[1, 0], [0, 1]],
               [[0, 1], [1, 0]]], dtype=np.float32)
b2 = 1.0

print(conv2d_naive(x2, k2, b2))
[[6. 7.]
 [3. 6.]]

출력은 2×2 특성 맵 [[6, 7], [3, 6]]이다. 손으로 구한 값과 같은지 확인한다. 채널별 결과는 따로 쌓이지 않고 더해져서 한 장이 된다.

5.3 F.conv2d와 대조

PyTorch의 콘볼루션은 배치 단위로 계산하므로 입력은 (N, C, H, W), 커널은 (출력 채널 수, 입력 채널 수, KH, KW)여야 한다. unsqueeze(0)으로 맨 앞에 축을 하나 더한다.

import torch.nn.functional as F

xt = torch.tensor(x2).unsqueeze(0)
kt = torch.tensor(k2).unsqueeze(0)
bt = torch.tensor([b2])

y = F.conv2d(xt, kt, bias=bt)
print(tuple(xt.shape), tuple(kt.shape), '->', tuple(y.shape))
print(y[0, 0].numpy())
(1, 2, 3, 3) (1, 2, 2, 2) -> (1, 1, 2, 2)
[[6. 7.]
 [3. 6.]]

입력 (1, 2, 3, 3), 커널 (1, 2, 2, 2), 출력 (1, 1, 2, 2)다. 값은 직접 계산과 같다. 커널의 두 번째 축은 입력 채널 수와 같아야 하고, 첫 번째 축이 커널의 개수이자 출력 채널 수다.

5.4 직접 해보기 ③ — 에지 검출 커널

왼쪽 두 열이 10, 나머지가 0인 5×5 흑백 이미지에 이론 6장의 세로 에지 커널을 적용한다. 출력 크기와 값이 큰 위치를 먼저 예상한다.

img_e = np.zeros((1, 5, 5), dtype=np.float32)
img_e[0, :, :2] = 10

# ① k_e에 (1, 3, 3) 모양의 세로 에지 커널 [[1,0,-1],[1,0,-1],[1,0,-1]] 만들기
# ② conv2d_naive(img_e, k_e) 출력

값이 큰 열이 밝음에서 어두움으로 바뀌는 경계의 위치다.

6. 출력 크기 공식

6.1 공식과 nn.Conv2d 대조

\[\text{출력 크기} = \left\lfloor \frac{N - K + 2P}{S} \right\rfloor + 1\]

파이썬의 //가 곧 버림이다. 공식으로 구한 값과 nn.Conv2d의 실제 출력 크기를 세 경우에서 대조한다.

def out_size(N, K, P, S):
    return (N - K + 2 * P) // S + 1

for N, K, P, S in [(7, 3, 0, 1), (32, 5, 2, 2), (28, 3, 1, 1)]:
    conv = nn.Conv2d(1, 1, kernel_size=K, stride=S, padding=P)
    real = conv(torch.zeros(1, 1, N, N)).shape[-1]
    print(N, K, P, S, '->', out_size(N, K, P, S), real)
7 3 0 1 -> 5 5
32 5 2 2 -> 16 16
28 3 1 1 -> 28 28

두 번째 경우는 \((32-5+4)/2 = 15.5\)를 버려서 15, 거기에 1을 더해 16이다. 반올림하면 답이 같아 보이지만 과정이 틀리다.

6.2 크기를 유지하는 패딩

커널 크기가 \(K\)일 때 \(P = (K-1)/2\)로 두면 입력과 출력 크기가 같다.

x_test = torch.zeros(1, 3, 32, 32)
for K in [3, 5, 7]:
    P = (K - 1) // 2
    y_same = nn.Conv2d(3, 8, K, padding=P)(x_test)
    print(K, P, tuple(y_same.shape))
3 1 (1, 8, 32, 32)
5 2 (1, 8, 32, 32)
7 3 (1, 8, 32, 32)

세 경우 모두 (1, 8, 32, 32)다. 커널 크기가 홀수여야 \(P\)가 정수가 된다.

7. 콘볼루션 층의 파라미터 수

커널 하나의 파라미터는 \(C_{\text{in}} \times K \times K\)개에 편향 1개다. 커널이 \(C_{\text{out}}\)개면 그 배가 된다.

conv = nn.Conv2d(3, 128, kernel_size=3, padding=1)
fc = nn.Linear(3 * 32 * 32, 128)

print(sum(p.numel() for p in conv.parameters()), 3 * 3 * 3 * 128 + 128)
print(sum(p.numel() for p in fc.parameters()))
3584 3584
393344

8. 작은 CNN으로 옷 사진 분류하기

8.1 세 종류만 고르기

FashionMNIST에서 티셔츠(0), 바지(1), 앵클부츠(9)만 골라 클래스당 1,500장을 쓴다. 정답 번호는 0, 1, 2로 다시 매긴다. 실습 4처럼 훈련·검증·테스트로 나눈다.

from torch.utils.data import Dataset, Subset
from sklearn.model_selection import train_test_split

KEEP = [0, 1, 9]
NAMES = [fmnist.classes[i] for i in KEEP]
remap = {c: i for i, c in enumerate(KEEP)}

tr_full = datasets.FashionMNIST(root='../data', train=True, download=True, transform=transforms.ToTensor())
te_full = datasets.FashionMNIST(root='../data', train=False, download=True, transform=transforms.ToTensor())

class Picked(Dataset):
    def __init__(self, base, idx):
        self.base, self.idx = base, idx
    def __len__(self):
        return len(self.idx)
    def __getitem__(self, i):
        x, y = self.base[int(self.idx[i])]
        return x, remap[y]

y_tr_all = np.array(tr_full.targets)
y_te_all = np.array(te_full.targets)
pool = np.concatenate([np.where(y_tr_all == c)[0][:1500] for c in KEEP])
tr_idx, va_idx = train_test_split(pool, test_size=0.2, random_state=42, stratify=y_tr_all[pool])
te_idx = np.concatenate([np.where(y_te_all == c)[0] for c in KEEP])

train_loader = DataLoader(Picked(tr_full, tr_idx), batch_size=128, shuffle=True)
val_loader = DataLoader(Picked(tr_full, va_idx), batch_size=256)
test_loader = DataLoader(Picked(te_full, te_idx), batch_size=256)

print(NAMES)
print(len(tr_idx), len(va_idx), len(te_idx))
xb, yb = next(iter(train_loader))
print(tuple(xb.shape), tuple(yb.shape))

8.3 학습

분류이므로 손실은 CrossEntropyLoss다. 학습 함수와 평가 함수는 실습 4의 것에 정확도 계산만 더했다. out.argmax(1)은 세 출력 중 가장 큰 자리의 번호, 즉 예측 클래스다.

criterion = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(cnn.parameters(), lr=0.01)

def train_one_epoch(model, loader):
    model.train()
    for xb, yb in loader:
        optimizer.zero_grad()
        loss = criterion(model(xb), yb)
        loss.backward()
        optimizer.step()

def evaluate(model, loader):
    model.eval()
    total, correct, n = 0.0, 0, 0
    with torch.no_grad():
        for xb, yb in loader:
            out = model(xb)
            total += criterion(out, yb).item() * len(yb)
            correct += (out.argmax(1) == yb).sum().item()
            n += len(yb)
    return total / n, correct / n

for epoch in range(8):
    train_one_epoch(cnn, train_loader)
    val_loss, val_acc = evaluate(cnn, val_loader)
    print(f'epoch {epoch}  val loss {val_loss:.4f}  val acc {val_acc:.4f}')

9. 직접 해보기 ④ — 커널 수 바꾸기

커널을 2개와 32개로 바꾼 CNN을 같은 방식으로 학습시켜 파라미터 수와 테스트 정확도를 비교한다. 아래 준비 셀은 그대로 실행한다.

def build_cnn(n_kernels):
    torch.manual_seed(42)
    return nn.Sequential(
        nn.Conv2d(1, n_kernels, kernel_size=5, padding=2),
        nn.ReLU(),
        nn.MaxPool2d(2),
        nn.AdaptiveAvgPool2d(1),
        nn.Flatten(),
        nn.Linear(n_kernels, 3),
    )

다음 셀의 주석을 코드로 바꾼다. 8.3절의 함수는 optimizer를 밖에서 만들므로, 모델을 만들 때마다 optimizer도 새로 만든다.

마무리

사진 한 장은 (H, W) 또는 (H, W, C) 배열이고, PyTorch에 넣을 때는 (C, H, W), 배치로는 (N, C, H, W)다. ToTensor와 Normalize가 표의 표준화에 해당한다. 콘볼루션은 곱해서 더하며 한 칸씩 옮기는 연산이고, 출력 크기는 \(\lfloor (N-K+2P)/S \rfloor + 1\), 파라미터 수는 이미지 크기와 무관하다. 학습 코드는 실습 3·4와 같다.

다음 실습 6에서는 오늘 지나친 풀링을 다루고, 콘볼루션 층을 여러 개 쌓아 컬러 사진을 분류한다.

직접 해보기 해설 — 먼저 작성한 뒤 확인

① 축 순서 되돌리기
